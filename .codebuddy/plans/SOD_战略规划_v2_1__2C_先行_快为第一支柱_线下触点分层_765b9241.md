## Product Overview

基于三轮调研成果与 CEO 四点反馈重审 SoD 战略，产出「战略规划 v2.1」版 PLATFORM.md：确立 **2C 先行**主线（2B 后置变现），竞争力体系重排为**四支柱**（快为第一支柱），滴滴平台化类比保持终局主角、仅后置实施；目标用户双 ICP 维持不变；Phase 0 重点详规为可直接执行的 12 周单城试点作战计划；同步修订 SOD.md/PRD.md 消除新旧叙事冲突。

## Core Features

- **2C 先行定位**：2B 冷启动更难、最终买单者是消费者，消费订单以小量个性化为主；2C 走通后 2B 顺渠道而下，2B 整体 solution 是长线变现途径。文档须收录三条路径证据（Sticker Mule 数十年后才 Stores/PRO 平台化、StickerYou 页装/卷装双轨分流 C/B 客群、映糖/柔造 C 端做大后反接机构单）与隐性收益（2C 数据复利是未来 2B solution 的差异化原料）
- **四支柱竞争力**（每支柱统一三问格式：是什么/为何结构性占位/Phase 0 如何验证）：① 快——当日达/当场拿，第一支柱，附**线下触点分层矩阵**（漫展摊位 > 谷子店/校园店挂机 > 商场快闪位 > 商场常驻 kiosk，按成本形态排序）；② 有图起点的 3 分钟成单管道（上传→AI 抠图→排版→下单）；③ 单张低价按张计价（9.9/7.9/5.9 累进继承）；④ 亲手+隐私+圈层信任
- **「从 0 到图」降级为辅助**：假设用户有图（自己在乎的内容）；AI 生图后置为辅助能力不当主角；作为 Phase 0 验证问题（访谈新增「你的图从哪来」）而非建设问题，整体列为 Phase 1+ 期权
- **滴滴类比双轨表述**：终局形态主角不降级、仅后置实施（Phase 1/2 骨架保留）；同时保留补贴禁用纪律（专用资产模式下补贴换供给无效；Redbubble 四年 A$7,000 万+ 付费获客未换来增长）
- **商场 kiosk 定位校准**：Phase 0 以低成本形态试验（快闪位/挂机），常驻 kiosk 为 Phase 1 验证后的放大器；商场日常流量对 ICP-B（年轻父母亲子场景）匹配度高于 ICP-A
- **目标用户维持不变**：ICP-A 二次元/谷子/手帐圈层（15-25 岁，周级高频，主攻）+ ICP-B 年轻父母含毛孩父母（25-35 岁，事件驱动）
- **三阶段路线图**：Phase 0 详规（12 周节奏、验证目标排序——付费意愿为最大缺口、Gate 0 继承+新增 2C 指标、漫展 vs 商场快闪同机对照实验、退出/转向条件、预算量级框架）；Phase 1/2 压缩为概要（2B 后置引入、常驻 kiosk 放大器定位、市集门槛吸收 Redbubble 教训）
- **文档体系同步**：SOD.md 定位章一句话定义与「明确不做」清单核对、PRD.md 适用范围对齐 v2.1 口径；不推翻 SOD.md 本质章（管道即资产、基础设施型）

## Phase 0 详规结构

- **验证目标排序**：① 付费意愿（PCV 最大缺口，《SoD市场调研和验证》§1.6）② 当日达履约体验（核心差异可行性）③ 2C 品牌心智
- **12 周节奏**：W1-2 备战（设备/选址/跑单表格/端上线）→ W3-6 冷启动（KOC 种草+免费打样+20 人圈层访谈并行，含「你的图从哪来」问题）→ W7-10 提频（复购运营+私域沉淀+当日达打磨+线下对照实验）→ W11-12 Gate 0 评审
- **Gate 0 指标**：继承（周订单 ≥100、创作→下单转化 ≥8%、30 日复购 ≥15%、单均 UE 边际 ≥0、SOP 文档化）+ 新增 2C 项（当日达兑现率、自提占比、私域沉淀率）+ 线下对照实验指标（漫展 vs 商场快闪同机自然流量转化率、分渠道 CAC）
- **退出/转向条件**（继承 v1 并按 2C 主线校准）
