## Product Overview

基于三轮调研成果（市场调研与验证、Sticker Mule 深拆、国内外 POD 五平台对标）重新审视 SoD 战略规划，更新为「战略规划 v2」：以**直接 2C** 为核心差异主线，重建竞争力体系，确认目标用户不变，重排三阶段路线图并重点详规 Phase 0 单城试点；同步修订既有产品文档，消除新旧叙事冲突。

## Core Features

- **2C 核心差异定位（需求 1）**：将「直接 2C」立为战略主轴。差异定义为「2C 深度」而非「是否 2C」——海外三强（Sticker Mule/StickerApp/StickerYou）确以 B2B 为根基；国内柔造/映糖形式上是 2C，但用户旅程从「有图」开始（传图代做升级版）。SOD 的 2C 深度体现在两端：旅程从「有想法」开始（从 0 到图），履约达消费级标准（当日达 vs 全行业排队 3-7 天）。滴滴类比降级为供给网络的内部结构参考，商业对标维持 Sticker Mule。
- **2C 竞争力五支柱（需求 2）**：① 从 0 到图的创作管道（编辑器即产品本体）② 当日达履约体验（S1 就近节点+自提+闪送，全场结构性空位）③ 圈层语言与审美信任（谷圈黑话 SKU 体系、KOC 渗透、差异圈层切入）④ 私域流量主权（Redbubble 有机流量崩塌的反面教训，获客成本从「租流量」改「自有资产」）⑤ 数据复利（作品库/审美偏好反哺编辑器与获客）。每支柱说明结构性依据与 Phase 0 验证方式。
- **目标用户维持不变（需求 3）**：双 ICP 确认——ICP-A 15-25 岁二次元/手帐/谷子圈层、ICP-B 年轻父母（含毛孩子父母）；附调研依据与「从 0 到图」对「不会画但想做」多数派的扩圈逻辑。
- **三阶段路线图（需求 4）**：Phase 0 单城自营试点**详规**——12 周节奏（备战/冷启动/提频/复盘）、三大验证目标排序（付费意愿为最大缺口）、Gate 0 继承原四指标并新增 2C 项（当日达兑现率、私域沉淀率、无图创作路径使用率）、退出/转向条件；Phase 1/2 压缩为概要级，叙事优先级按 2C 主线校准，Phase 2 市集门槛吸收 Redbubble 教训。
- **文档体系同步**：SOD.md 定位章、PRD.md 适用范围对齐 v2；v2 不推翻 SOD.md 本质章（管道即资产、基础设施型）。

产出为纯战略文档成果，无界面改动；核心价值是让战略叙事从「平台先行」反转为「2C 品牌先行、平台为支撑」，并以 Phase 0 作战计划可直接执行。

## 任务性质与产出物

纯文档任务（Markdown），不涉及代码。三份调研文档是事实底座，所有竞品论断与数据必须可回溯引用，不得新增未经调研的断言。

## 写作策略

**版本升级而非全盘重写**：`PLATFORM.md` 保留文件名、内容重写为 v2，头部注明版本沿革（v1 平台化战略 → v2 2C 校准）及与 v1 的继承关系。v1 中已被调研验证的骨架（三阶段结构、Gate 门槛纪律、自营 vs 购买决策表、起步两难分析）继承保留，仅重排叙事优先级；被推翻或降级的部分（滴滴类比地位、终局叙事主角）显式说明降级理由，保留决策痕迹。

**「2C 深度」定义的诚实纪律**：不得使用「竞品不做 2C」的绝对表述（柔造/映糖形式上是 2C）；差异口径统一为「旅程起点（有图 vs 有想法）× 履约标准（快递级 vs 消费级）」两轴，与《StickerMule深度分析》§7.2「工具哲学差异」口径处理方式一致。

**五支柱统一格式**：每支柱回答三问——是什么 / 为什么是结构性占位（竞品为何做不到：成本模型/组织能力/模式冲突）/ Phase 0 如何验证（对应哪个 Gate 指标或验证动作）。

**Phase 0 详规结构**：验证目标排序（① 付费意愿——PCV 最大缺口；② 当日达履约体验——核心差异可行性；③ 2C 品牌心智）→ 12 周作战节奏（W1-2 备战：设备/选址/跑单表格/端上线；W3-6 冷启动：KOC 种草+免费打样+20 人圈层访谈并行；W7-10 提频：复购运营+私域沉淀+当日达体验打磨；W11-12 Gate 0 评审）→ Gate 0 指标（继承：周订单 ≥100、转化 ≥8%、30 日复购 ≥15%、单均 UE 边际 ≥0、SOP 文档化；新增 2C 项：当日达兑现率、自提占比、私域沉淀率、无图创作路径使用率）→ 退出/转向条件 → 预算与人力框架。

**一致性规则**：v2 不推翻 `SOD.md` 本质章；凡与 v2 冲突处以 v2 为准；`SOD.md`/`PRD.md` 仅做对齐性微修（定位章一句话定义、明确不做清单、PRD 1.1 适用范围），不动其推导过程。
