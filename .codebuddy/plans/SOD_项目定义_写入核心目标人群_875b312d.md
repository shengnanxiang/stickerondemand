## 产品概述

SOD（Sticker on Demand）是一个提供「在线定制-下单-送货上门」全链条服务的在线贴纸 DIY 项目，用于消除 1500 元贴纸打印一体机的硬件门槛。本次任务是把已通过问答确认的「核心目标人群」内容正式补写进 SOD.md。

## 核心内容

- **补全「核心目标人群」章节**：将已定稿的 `特征`、`痛点`、`需求` 三个空白小节填入 SOD.md。
- **保留并标注 `场景`**：保留现有两条（聚会庆生、物件点缀），并注明其为示例、不封闭，后续可持续补充。
- **痛点只保留三条扎实洞察**：硬件门槛高、DIY 参与感弱、隐私顾虑。
- **需求只列三条主要需求**：零硬件门槛在线创作（Web 端）、高参与度编辑器、单张低价无起订。
- **必备属性（隐私、耐久品质）不写入需求**，留待后续统一罗列。

## 边界与约束

- 不改动「定位」部分（一句话定义 / 愿景 / 核心价值）。
- 不新增其他文件，仅编辑 SOD.md。
- 需求中不提小程序，第一步明确只做 Web App MVP、不做多端。
- 不写入已否决的条目：即时性/闪送、便利（省跑店）、起订量不灵活、不会做/做不好。

## 实现说明

本次为纯文档内容填充任务，不涉及代码与技术栈，仅编辑既有 Markdown 文件。

## 文档结构与约定

- 沿用 SOD.md 现有标题层级：`#` 一级（SOD / 定位 / 市场与用户洞察）、`##` 二级（核心目标人群）、`###` 三级（特征 / 场景 / 痛点 / 需求）。
- 正文统一使用无序列表（`-`）与有序列表（1. 2. 3.），与文件既有风格保持一致。
- 中文标点与全角括号「」沿用原文风格；`场景` 小节保留用户原有编号列表（1. 2.）与措辞，仅追加一句非穷举说明。
