## 1. 切割对象与材料分析

> 本章 v1.1 结论经复核全部继续有效。v2.0 补充判断见 1.4 节：走刀式渐进切割对相纸的应力集中小于模切压切，材料学风险不升反降。

### 1.1 Zink 相纸（2x3，口袋照片打印机）

**【事实】**
- Zink（Zero Ink）是无墨打印技术：相纸内含黄/品红/青染料晶体层，打印头热激发显色（来源：ZINK 官网 zink.com；新浪科技技术介绍）。
- Zink 相纸**普遍自带背胶**：HP Sprocket 2x3 相纸官方描述"不干胶设计，撕开即贴"；米家口袋照片打印机官方在售相纸即为"背胶即贴相纸"（来源：京东在售商品）。
- 单张价格：50 张装零售约 ¥79，折合约 ¥1.5～1.6/张。

**【推断】（置信度：高）**
- 相纸厚度约 200～300μm（背胶层+基材+三层显色晶体层+保护层）。依据：功能层堆叠下限约 150μm，上限受口袋打印机窄纸道约束。
- "切透照片层、不切透离型底纸"的半切在层间弱界面进行，为不干胶行业成熟工艺。

### 1.2 染料热升华相纸（4x6 与 3 寸，照片打印机）

**【事实】**
- 米家照片打印机 1S 6 寸相纸：官方描述自带背胶设计，自动覆膜（来源：京东商品页）；40 张+色带套装约 ¥99。
- 热升华相纸结构：接收层+基材+O 层覆膜；厚度高于 Zink；走纸往复 4 次（YMCO），单张约 1 分钟。

**【推断】（置信度：中高）**
- 热升华相纸总厚约 250～350μm。
- 两种相纸层间弱界面位置不同（Zink 70%～80%、热升华 75%～85% 厚度处），**切深参数需分耗材 SKU 配置**——数控刀头的软件切深参数库恰好是自有一体机平台应已解决的问题（Gate③ 核对项）。

### 1.3 背胶 SKU 结论

**【事实】**
- 米家生态已有背胶相纸在售：口袋打印机 2x3"即贴相纸"、1S 6 寸相纸（背胶）、1S 3 寸背胶相纸 **86×102mm（近方形 3R 系幅面，非正方形）**，40 张/包 ¥99～118（来源：京东商品页、苏宁商品参数页、1688 在售 SKU 含 3 寸专用色带；mijia-pm 双轮检索交叉验证）。
  - 勘误留痕（v1.1）：v1.0 曾标注"3x3.25 英寸"，系笔误，无来源支撑。
  - **规格裁决（Leader 已采纳，v2.0 不变）**：物理纸规格三种（2x3 / 3寸 86×102 / 4x6）；"3×3 正方形"由 3 寸纸内 76×76 方贴轮廓承载（76+2×2mm 出血=80mm ≤86/102 双向）；4x6 裁切路线否决（纸面利用率差）。

**结论**：无需从零创建背胶相纸品类；需与耗材团队确认批次厚度一致性（影响切深窗口公差分配）。

### 1.4 相纸厚度对切割的影响（v2.0 补充）

- 两种相纸厚度均在 200～350μm，属"薄膜+不干胶"常规范围，无材料学障碍【推断，置信度高】。
- **v2.0 判断**：走刀式渐进切割的瞬间应力只作用于刀尖接触点，远小于模切压切的刀刃全线应力集中；Zink 显色层受挤压变色的风险面从"整条切线"收窄为"刀尖轨迹附近"，**切线变色带预期比模切更窄**（待 7.1 节实测项 1 量化）【推断，置信度：中高】。Zink 软纸的卷曲风险由嵌件+压纸框压平机构消解（4.1 节）。

## 2. 切割原理选型（v2.0 复用前提重写）

### 2.1 前提变化

v1.0/v1.1 对方案 C 的否决建立在**全新开发**假设上（BOM ¥450～700、零售 ¥1299+，撞极印锚点）。用户新增事实【事实：用户提供，未经内部资料核实】："公司自有照片打印切割一体机已在用数控刀头，技术已解决"——XY 传动、刀头模组、控制板卡、切深参数库为**已量产验证的存量资产**，其历史开发与模具摊销（原估约 ¥180～280/台）对复用项目归零。

**复用的边界（本报告最重要的工程判断）**【推断，置信度：高】：
- **可移植**：刀头模组、XY 传动、电机驱动、运动控制固件、切深参数库——"切割执行"资产；
- **不可移植**：打印→切割的**对位基准**。一体机切割精度建立在内部机械传递连续性上（打印与切割共享同一纸道坐标系）；拆为独立配件后用户手工放置打破该连续性，±0.3～0.5mm 放置误差必然出现。**"切割技术已解决"≠"配件化对位已解决"**——独立配件必须重建对位基准，这正是引入 CIS 视觉对位（第 3 章）的原因。

### 2.2 候选对比（复用前提）

| 维度 | A：模切刀盒 | C：数控刀头（复用）+ CIS 对位 |
|---|---|---|
| 可切任意图案 | ✗ 仅预置轮廓（换轮廓=换刀盒 SKU） | ✓ 任意轮廓（L3 自定义 + 12 枚拼版第一代解锁） |
| 对位精度 | 机械对位 ±0.3～0.5mm（放置误差不可修正） | **机械粗定位 + CIS 修正 → ±0.1mm**（放置误差被系统性吸收） |
| 体积 | 小（约 220×130×90mm） | 中（约 300×200×120mm，仍小于 Cricut Joy Xtra 的 445×135×160mm 级）【推断】 |
| 噪音 | 低（单次压切 3～8 秒） | 中（电机+刀尖摩擦，持续 15～120 秒） |
| 寿命/耗材 | 刀盒耗材化（3 年/5 万次，¥29～39） | 刀片耗材化（1 年/500 米刀路，¥19～29，见 6.4）；**轮廓上新=云端参数，零硬件 SKU** |
| BOM（±30%） | ¥170～320 | **¥196～337**（5.2 节分解） |
| 单张时长 | 3～8 秒 | 15～120 秒（6.2 节时长表） |

**对比结论**：复用使 C 的两个历史短板（成本、开发风险）消失；A 的两个优势（成本、速度）中成本优势已消失（区间重叠），仅剩速度——而家庭场景对 30～90 秒不敏感（打印本身 50～60 秒）。**C 在功能维度全面胜出**。

### 2.3 推荐（v2.0）

**推荐：方案 C（复用自有数控刀头平台 + CIS 视觉对位）为第一代方案。方案 A 降为回退路线（附录 A），触发条件见 3.4 节。**

1. **产品主张跃升**：从"预设轮廓贴纸配件"升级为"任意轮廓贴纸机"——第一代即支持 L3 与 12 枚/4x6 拼版，正面对标 Cricut Joy Xtra（海外 $179～199）且预计零售便宜一半以上。
2. **成本结构反转**：复用 BOM ¥196～337 与 A（¥170～320）重叠，A 的存在意义只剩 Gate 失败时回退。
3. **对位痛点彻底解决**：用户与研发的核心担忧（手工放置误差）由 CIS 修正层系统性吸收，比机械对位的"拒绝式防呆"高一个代差。
4. **运营自由度**：轮廓上新=云下发参数（复用 03 方案轮廓库运营机制），无刀盒 SKU 供应链；"3x3 方贴"等轮廓全部软件化。

## 3. 对位方案（v2.0 重写：双层架构）

### 3.1 双层对位架构

**第一层：机械粗定位（嵌件+压纸框，继承 v1.1 设计）**
- 相纸插入分规格嵌件，挡块约束位置与方向：**粗定位目标 ±0.5～2mm 平移、±2° 以内旋转**（确保落入 CIS 修正范围并完成规格/方向识别）【推断，置信度：高】。
- 继续承载：规格识别（嵌件编码+规格卡片）、放向防呆（非对称挡块）、E4 互锁——03 方案交互设计全部不变。

**第二层：CIS 视觉精修正**
- 版式四角冗余区印定位标（03 方案 3.1 节 Cut Alignment Mark，v1.0 仅为二代预留，v2.0 升格为第一代核心对位手段）。
- 机内 4 英寸幅宽 CIS 线阵模组（含 LED 照明）：滑架携 CIS 横扫四角定位标窗口（每标约 20×20mm，不必全幅扫描）→ MCU 模板匹配解算四标中心 → 仿射变换解算平移+旋转 → 修正刀路坐标系。
- **精度**：300dpi CIS 像素 0.085mm，标记中心亚像素检测 **±0.1mm 级**（对标 Cricut Print Then Cut 标称与工业定位标记识别惯例）【推断，置信度：中高】。
- **对位耗时 3～5 秒**（滑架移动+窗口扫描+计算），不挤占主线 5 分钟预算。

### 3.2 精度与良率（v2.0 重算）

| 场景 | 误差预算 | 预期良率 |
|---|---|---|
| L1 整版（三规格） | CIS 修正后总误差 ±0.1～0.15mm | ≥99.5% |
| L2 拼版 12 枚 25mm 圆/4x6 | 同上（平移误差被逐张修正吸收，无系统性偏移） | **≥99%** |
| L3 自定义轮廓 | CIS 对齐打印出血区，±0.15mm | ≥98% |
| 3 寸纸 76×76 方贴 | 同 L1 | ≥99% |

**v1.1 判定撤销说明**：v1.1 因"机械对位误差为整版平移型、12 枚阵列放大视觉可感"判定 12 枚拼版不进第一代。CIS 把误差从 ±0.3～0.5mm 压至 ±0.1mm 且逐张修正消除系统性偏移，判定前提不再成立——**12 枚/4x6 与 L3 自定义轮廓均进入第一代能力清单**。

### 3.3 刀路数据通道（维持 v1.1 裁决，载荷升级）

- **通道形态选型（供 03 引用）**：
  - **预置轮廓**：Beacon 广播帧下发轮廓 ID（1 字节级），机内 16～32 个参数化轮廓集（圆 3 尺寸/圆角矩形 3/花边 4/标签 4/对话气泡 2/日期框 2/76×76 方贴 1 等），CIS 偏移在机内实时合成最终刀路；
  - **L3 自定义轮廓**：**GATT 握手通道（连接态）下发矢量点集**，路径点压缩后典型 <2KB，2～5 秒传完；**不采用广播帧分段**——广播无链路层重传，丢帧乱序即废纸风险；GATT 连接态有可靠重传。Beacon 广播继续用于状态/事件/进度（03 方案体系不变），L3 场景临时建立 GATT 连接，App 显示"正在传输轮廓"。
- **反对边缘暗码的论证全部维持**（v1.1 3.3 节四维表：传感器成本+暗码失败率+卡纸敏感度），v2.0 下 BLE 可重传的特性更加不可或缺。
- 打印定位标随版式打印，已是第一代核心依赖（不再是"二代预留"）。**注意**：此依赖把 03 方案【假设3】（打印渲染管线叠加能力）的优先级上浮为阻塞项（见 7.2 节）。

### 3.4 切换 Gate（三项硬指标，任一不满足回退方案 A）

> **Gate 为 EVT 前一次性定案**：定版后硬件结构锁定，不存在量产后 OTA 回退至模切的路径；模切是"立项期备选路线"（03 表述），不是常备 Plan B。CIS 运行期退化（镜头脏污）由固件开机自标定兜底，不触发 Gate。

| Gate | 硬指标 | 判定阶段 | 责任方 |
|---|---|---|---|
| **Gate① 模组成本** | 刀头+XY 传动模组内部采购/结算价 **≤¥120/台** | 立项/预算评审（一次性） | 硬件+采购（对自有平台核账） |
| **Gate② CIS 精度** | CIS 对 86×102mm 幅面四标实测识别精度 **≥±0.15mm**（含 Zink 反光、压纸框光损工况） | EVT/DVT 样机实测 | 硬件 |
| **Gate③ 参数迁移** | 自有平台切深控制对 Zink 与热升华两种相纸的半切参数**可迁移确认**（供应商参数库或样机验证） | EVT 样机验证 | 硬件+一体机研发团队 |

**回退决策点最晚在 EVT 中期**；晚于此回退将损失 C 方案模具投入（约 ¥40～60 万【推断】）。回退后的方案 A 形态见附录 A。

## 4. 结构可行性

### 4.1 三规格共存（嵌件体系不变，走刀机构新增）

- **嵌件体系不变**：单一 U 型纸道 + 分规格可换嵌件（2x3/3寸/4x6 各一随机标配），机械编码互锁、规格卡片识别、放向防呆全部保留——第一层对位与防呆依赖它。
- **走刀行程**：XY 行程覆盖 4x6（102×152mm）+定位标窗口冗余，X 滑架行程约 200mm、介质承载 Y 向约 160mm；**CIS 与刀头共轨**（同一 X 轴滑架，先扫后切）省一套传动【推断，置信度：中】。
- **新增压纸框**：走刀全程压平相纸（Zink 软纸卷曲会撞刀尖），嵌件上盖集成透明 PC 压框，CIS 透过压框扫描（照明补偿压框光损）【推断，置信度：中高】。
- **体积量级**：约 **300×200×120mm、1.2～1.8kg**【推断，置信度：中】——比模切版大 50%，仍显著小于 Cricut Joy Xtra，"桌面配件"心智可保。

### 4.2 与一体机平台的共用边界

- 共用：刀头模组、XY 传动件、电机驱动板、运动控制固件栈、切深参数库（Gate③ 后）。
- 新开发：嵌件纸道（配件的放置-防呆需求与一体机内部纸道完全不同）、CIS 对位子系统（一体机不需要）、Beacon 通信、独立壳体。
- **结论：这是"模组复用"而非"整机衍生"，工程量约为全新开发的 50%～60%**【推断，置信度：中】。

### 4.3 Zink 相纸的参数适配（走刀版）

Zink 显色层对温度与应力敏感（受硬物刮擦留显色痕迹为公认特性，【事实】用户手册提示避免刮擦）。走刀对策：切深参数按 Zink 专项标定（浅切深+中低刀速）+ 切线出血区 ≥2mm + 压纸框全程约束（消除褶皱应力）——比模切压切的应力环境更温和（1.4 节），列入 7.1 实测项 1。

## 6. 可靠性与安全设计（v2.0 按走刀式重排）

### 6.1 卡纸与走刀异常、断点续切

- **卡纸机理**：走刀式新增"刀尖钩纸"风险（切深过深或纸面褶皱），但嵌件+压纸框全程约束相纸，风险敞口集中在纸面异物与压框未扣合——上盖/压框任一未闭合→电机硬件断路（继承 v1.1 安全开关设计）。
- **堵转与过流保护**：Z 向刀压监测+电机电流双通道，异常 <100ms 停机【推断，工程惯例】。
- **断点续切（需用户确认，非全自动）**：中断→刀头抬 Z 安全高→MCU 掉电保存刀路指针+XY 坐标（Flash）。恢复：用户排除障碍后**按切割键确认**→滑架自动回零→跳至断点前 2～3mm 重叠量续切（保证接缝质量）→CIS 复核纸位（相纸被重放、坐标偏移超阈值则提示"纸张已移动，建议重切本张"）。三种恢复结果：续切完成/提示移动/确认报废。（对齐 03 v2.0 E3 交互。）

### 6.2 切割时长表（走刀速度 5～8cm/s 半切【推断】）

| 版式 | 时长 |
|---|---|
| 2x3 整版 | 15～25s |
| 3 寸整版/方贴 | 25～40s |
| 4x6 整版 | 45～70s |
| 4x6 拼版 12 枚 | 60～90s（12 次抬落刀占大头） |
| L3 自定义轮廓 | 60～120s（App 端复杂度护栏把关） |

App 按轮廓长度实时估时显示（03 修订项）。模切版 3～8 秒的速度优势不再存在，家庭场景可接受（打印 50～60s 在前）。

### 6.3 CIS 失败分级（不降级机械对位）

| 识别结果 | 机器行为 | App 提示 |
|---|---|---|
| ≥3/4 标识别 | 用剩余标解算，继续切 | "已用 3 标对位"（轻提示） |
| <3 标识别 | **拒绝启动** | "定位标污损，请擦拭后重插" |
| 完全无标 | 拒绝启动 | E8：非贴纸版式打印（v1.1 设计不变） |

**不降级原因**：C 是参数化任意刀路，机械对位 ±0.3～0.5mm 对任意轮廓安全余量不足——降级=产生不合格品，宁可拒绝。CIS 镜头脏污属维护项：固件开机自标定（扫机内基准版）兜底。

### 6.4 刀片耗材与安全（含寿命口径，供 03 引用）

- **刀片寿命口径**：标称 **1 年 / 500 米累计刀路，以先到者为准**【推断，置信度：中】。依据：刻字机行业碳钨钢刀片典型寿命 1000～3000 米刀路（视材料）；家用贴纸场景单张刀路 0.3～1 米、年 1800 张≈600～1800 米，取保守值 500 米。注：C 方案刀片寿命短于模切刀盒（刀尖应力集中+反复抬落刀），到寿提示经 Beacon 推送（E4 新增交互），引导购买刀片。
- **刀片为独立耗材 SKU**：建议零售 **¥19～29/片（双片装 ¥29～39）**【推断】；cartridge 化全包覆刀座（换刀不触碰刃口），复用自有平台刀片生命周期管理体系（到寿计数在 MCU，配刀片一起复位）。
- **安全设计**：上盖+压框双闭合硬件联锁；双条件启动（纸到位+盖闭合才响应切割键）；无外露刀刃。

### 6.5 儿童安全

无外露刀刃+封闭行程+双条件启动+防护设计（同 v1.1 原则）；GB 4706.1 + GB 6675 锐边自检建议不变【推断：标准清单待法规专员确认】。

## 8. 总结论（v2.0）

1. **推荐反转**：基于自有数控刀头平台复用，第一代方案由模切刀盒切换为**复用数控刀头 + CIS 视觉对位**；三项 Gate（模组结算价 ≤¥120 / CIS 精度 ≥±0.15mm / 半切参数迁移）EVT 前一次性定案，任一不满足回退模切（附录 A）。
2. **对位升级为双层架构**：机械嵌件粗定位（防呆+规格识别）+ CIS 精修正（±0.1mm）；12 枚/4x6 拼版与 L3 自定义轮廓进入第一代能力清单（良率 ≥98%）。
3. **成本**：复用 BOM ¥196～337，与模切重叠；支撑零售 ¥699～799（首发 ¥599 可讲），不到 ¥1599 锚点一半。
4. **刀路通道**：维持 Beacon 轮廓 ID 裁决；预置轮廓走广播帧轮廓 ID，L3 走 GATT 矢量点集下发（<2KB，2～5 秒）；反对边缘暗码论证不变。
5. **复用边界**："切割技术已解决"≠"配件化对位已解决"——内部机械传递连续性不可移植，独立配件必须重建对位基准；CIS 是该问题的解，也是相对一体机与 Cricut 的差异化体验来源。
6. **给 Leader 的产品建议**：以"¥699～799 / 复用一体机切割技术的独立配件 / 任意轮廓+修正对位"叙事上市；Gate 三项在立项评审与 EVT 两阶段收敛；03 方案嵌件/规格卡/Beacon 交互体系零变更兼容，刀片耗材（1 年/500 米，¥19～29）替代刀盒耗材线。
