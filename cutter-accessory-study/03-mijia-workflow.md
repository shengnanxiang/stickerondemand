## 0. 摘要（供快速决策）

- **推荐接入形态**：分体两件套——「从属切割配件（无独立通信）+ 相纸规格识别锚点」。切割机在米家App中**不作为独立设备出现**，而是把「制作切割贴纸」入口内嵌到**现有打印机插件**，切割机绑定后寄生于打印机插件的配件栏（类似打印机纸盒/校准卡的位置认知）。硬件基线为**方案 C：XY 数控刀头 + CIS 视觉对位（±0.1mm）**（02 报告 v2.0，公司一体机数控刀头技术复用），三项硬 Gate 任一不满足则回退模切方案；保留一个可选的蓝牙 Beacon 通道（广播状态+下发轮廓任务，不建独立设备模型）。
- **一句话理由**：产品目标是"低价配件"，用户心智是"打印机的延伸功能"而非"新设备"；从属配件形态省掉独立设备模型/配网/插件审核链路，BOM 最省、插件入口心智最顺；方案 C 复用公司既有数控刀头技术后 BOM（¥196~337）与模切重叠，却带来 ±0.1mm 对位精度与"任意轮廓"能力，恰好能兜住 2x3/3寸/4x6 三种物理规格（覆盖用户语言的 2x3/3x3/4x6 需求）的质量底线并解锁自定义轮廓。
- **用户旅程主线**：打印机插件 → 首次引导绑定切割机 → 选照片 → 选贴纸版式（单张整版/多枚拼版/自定义轮廓，三者第一代全开）→ App 下发轮廓任务并叠加打印定位标 → 打印 → 插入切割机 → 机上单键启动 → CIS 自动扫描对位 → 走刀切割（App/机身反馈对位与切割进度）→ 出料揭贴。全程主线不超过 3 层页面。
- **第一代版式能力（v2.0，CIS ±0.1mm）**：4x6 拼版开放至 25mm×12 枚；L3 自定义轮廓第一代解锁（指尖圈画轮廓，CIS 保证出血区对齐）——模切时代的密度白名单与"L3 二代开放"限制全部解除；二代增量转向更大画幅与更多轮廓库。
- **3x3 规格口径**：米家照片打印机 1S 原生支持 3 寸相纸（86×102mm，近方形 3R 幅面）且 3 寸背胶相纸官方在售——用户语言"3x3"由 3 寸纸上的 **76×76mm 方贴轮廓**承载（见 4.4）。
- **对现有插件的关系**：推荐「现有插件功能增强」路线，不做独立插件；切割能力以「能力开关」形式按配件绑定状态动态出现，未绑定用户零打扰。
- **平台侧需要**：现有打印机插件升级、跨设备/配件绑定关系（含绑定记录云同步）、贴纸轮廓资源云下发、耗材余量估算与商城跳转、一处打印定位标规范定义（CIS 对位的读取对象，规范地位从"二代预留"升为"一代必需"）。

## 1. 背景与设计输入

### 1.1 用户与场景假设

- 目标用户是**已拥有**米家口袋照片打印机（2x3，Zink）或米家照片打印机1S（3/6 寸，热升华）的存量米粉，想把手拍照片做成贴纸（手帐、手办改娃、水杯/笔记本装饰、儿童玩教具）。
- 用户对"打印机App里多点两步"接受度高（米家插件本就是打印主入口），对"再装一个App/再配一次网"敏感——这是配件形态最重要的体验约束。
- 高频场景是**单张照片快速做贴纸**（<5 分钟出成品）；低频但重要的场景是**批量做拼版贴纸**（手帐周计划、儿童奖励贴）。

### 1.2 产品事实输入（已核实/待核实）

### 1.3 设计原则

1. **打印机插件是唯一主入口**——用户心智里"打印"已在米家App里，切割不该另开认知。
2. **主线 3 步内可完成**：选照片 → 选版式 → 打印+切。
3. **每次额外操作都要能被免除**：绑定一次后，规格识别、方向校验尽量自动化。
4. **异常兜底优先用纸面引导**（印刷图示 + 插件动画），少弹错误弹窗。
5. **耗材闭环**：切割贴纸纸包本身承担耗材入口（余量估算 + 商城一键购）。
6. **失败可恢复**：任何中断（App 杀掉、切到一半断电）不产生废纸以外的损失，重试成本低。

## 2. 接入形态评估与推荐

### 2.1 候选形态对比

| 维度 | A. 独立米家设备（BLE/WiFi 自配网） | B. 从属配件（无独立通信，纯机械） | C. 推荐：分体两件套（从属配件 + 规格识别锚点） |
|---|---|---|---|
| 米家App呈现 | 首页独立设备卡片、独立插件页 | 不出现，功能寄生于打印机插件 | 打印机插件内「配件栏」出现，首页不新增设备卡 |
| 配网/绑定成本 | 完整配网流程（扫码/广播发现/配对），用户多学一套 | 零配网，插上即用 | 首次扫描配件二维码在打印机插件内"绑定"，一次完成 |
| BOM 成本 | WiFi 模组或 BLE+加密芯片、独立设备证书、天线 | 纯机械/传感，最省 | 机械识别 + 1 颗 BLE Beacon 芯片（广播自定义厂商数据帧，不建设备模型） |
| 进度反馈能力 | 强（完整遥测） | 弱（只能靠机身指示灯与用户观察） | 中强：Beacon 状态帧 + 机身指示灯，App 前台可直接显示 |
| 平台接入工作量 | 需新建设备模型、新插件、过米家认证（周期长） | 插件升级 + 云端资源，工作量最小 | 插件升级 + 云端资源 + Beacon 数据帧私有协议（不占用标准设备模型） |
| 跨设备体验 | 切割机与打印机是两台设备，用户需在两插件间切换 | 天然一体 | 天然一体 |
| 商业叙事 | "米家贴纸切割机"可独立营销，但价格锚点上浮 | "打印机配件"，低价配件叙事成立 | 同 B，且保留"智能配件"故事点 |
| 生态一致性 | 与耳机/手环等独立蓝牙设备一致 | 与"纸盒、校准卡"等耗材配件一致 | 米家生态已有"配件寄生于主设备"的先例（如扫地机配件尘袋在主设备插件内显示状态） |

### 2.2 接入形态推荐：C（分体两件套）

**推荐理由**：

1. **成本红线**：产品定位是"低价配件"（对标极印一体机 ¥1599 做低价切入）。形态 C 的 BOM 省去 WiFi/BLE 完整通信栈与独立设备证书，BLE Beacon 芯片量级成本可忽略；方案 C 数控刀头经公司一体机技术复用后 BOM ¥196~337，与模切方案重叠（02 报告 v2.0），整机成本仍压在配件价位带。
2. **体验主线**：用户旅程完全在打印机插件内闭环，不出现"第二个设备"的心智负担；打印→切割的连续性靠**同一插件内两个设备的任务串联**实现，而不是让用户在两个插件间搬运照片。
3. **规格识别刚需**：三种物理相纸规格（2x3 / 3寸86×102 / 4x6，覆盖用户语言的 2x3/3x3/4x6 需求）如果全靠用户在 App 手选，放错纸的比例会显著上升。形态 C 用**机械锚点**解决：每种规格的切割贴纸纸包附一次性"规格卡片"（形状与口袋打印机橙色校准卡同思路，见 4.2），插入切割机后机器即知道当前纸型，App 同步显示——**把规格识别从交互问题变成机械问题**。
4. **对位双保险**：机械嵌件+压纸框做第一层（粗定位到 CIS 修正范围内），CIS 视觉对位做第二层（精修至 ±0.1mm）——放不歪是防呆，放歪了能救，两层职责分离（见 3.3）。
5. **保留升级空间**：Beacon 通道让第一代就具备进度反馈与轮廓任务下发；若第二代要更大画幅/更复杂遥测，可平滑升级为独立设备形态，不影响第一代用户。

**对形态 A（独立设备）的否定理由**：配网流失、插件审核与认证周期、双插件割裂体验、BOM 上浮——四项叠加后与"低价配件"定位冲突。它更适合作为**未来高端版**（"米家贴纸大师"）的形态。

**对形态 B（纯从属）的保留意见**：若 BOM 极限压缩导致连 Beacon 都砍掉，体验上将退化为"盲切"（用户按下切割键后只能盯着机器），进度反馈全靠机身灯。可接受但不推荐；Beacon 是本方案体验的关键增量，成本很小。

### 2.3 绑定模型：配件绑定关系

- 绑定对象：**打印机（已有米家设备） + 切割配件（二维码序列号）**，绑定关系记录在云端账户下（【假设1】）。
- 一个切割配件默认绑定一台打印机；插件内支持「更换主机」操作（换打印机后重绑，无需重新购买任何东西）。
- 一台打印机插件可显示切割配件状态（在线/离线、固件版本、耗材余量）。
- 未绑定时，打印机插件内切割入口显示为灰态+引导态；绑定为一次性 3 步流程（见 4.1 首次使用）。

## 3. 关键技术交互概念定义

在写旅程前，先定义三个贯穿全程的核心概念，避免旅程描述中含糊：

### 3.1 打印定位标（Cut Alignment Mark）

- 定义：打印在每张贴纸版式**四角冗余区**的高对比度标记（4 个定位标 + 方向码），是 **CIS 视觉对位的读取对象**（v2.0 起为一代必需，不再是"二代预留"）。
- 对位流程（02 报告 v2.0）：插纸到位 → CIS 滑架横扫四个 20×20mm 标记窗口（非全幅扫描）→ 四标中心解算仿射偏移（含平移+旋转）→ 修正刀路 → 落刀，全程 **3～5 秒**。
- 容错设计：识别 ≥3/4 标即可用剩余标解算继续切（App 提示"已用 3 标对位"）；<3 标拒绝启动（见 E 系列）；无标 = 非贴纸版式相纸（E8）。
- 规范需在平台侧统一定义（见 7.4），是本方案对米家平台侧的**新增规范依赖**（从"若暂无则建议"升为"上线必需"）。

### 3.2 规格识别锚点（Format Anchor）

- 定义：切割贴纸纸包内附的一次性卡片，不同规格（2x3 / 3寸86×102 / 4x6）卡片的**物理形状/孔位排列**不同，插入切割机的识别槽后：
  - 机械上：卡片顶住微动开关组合 → 机器识别出 2-bit/3-bit 规格编码；
  - 插件上：用户首次插入新规格卡片时，Beacon 广播规格变更事件，App 弹出确认（"检测到 3 寸贴纸纸包，已就绪"）。
- 生态先例：口袋打印机橙色校准卡（条形码向下放在纸包最下方）证明"纸包附卡片承载机器可读信息"在米家打印生态是成熟做法。
- 成本含义：几乎零电子成本（微动开关组合），在 CIS 方案下规格识别仍走机械锚点而非 CIS 识别——把"识别"与"对位"两个问题分离，CIS 专注于精度修正。

### 3.3 机械底座（第一层防呆）与 CIS 对位（第二层修正）——双层结构

- **第一层：嵌件+压纸框（机械粗定位与防呆）**
  - 定义：切割机出厂标配三个可换嵌件（对应 2x3 / 3寸 / 4x6 三种物理规格）+ 压纸框（相纸放入后压平定位）。
  - 职责：① 把相纸粗定位到 **CIS 修正范围内（±2mm / ±2°）**——嵌件挡块保证插入方向与位置基本唯一，压纸框保证走刀期间纸面平整不翘曲；② 承载规格识别（配合规格卡片）；③ 放向防呆（反向物理插不进，见 E2）。
  - **刻意保留机械层的理由**：方案 C（数控刀头）业界惯例（Cricut 路线）依赖**低粘垫板**固定相纸——那是新增耗材（垫板粘性衰减需更换、贴纸揭取与垫板粘连影响体验）。本方案用"嵌件+压纸框"替代垫板，**保住"无新增耗材"卖点**：用户买相纸即可，无任何附加物料。
- **第二层：CIS 视觉对位（精修）**
  - 定义：CIS 线阵传感器扫描四角定位标，解算打印坐标系与刀路坐标系的仿射偏移，把机械层的 ±0.5mm 量级误差精修至 **±0.1mm**。
  - 职责：精度兜底与"放歪了也能救"——用户放纸存在小偏差时无需重放，CIS 自动校正（这是 L3 自定义轮廓与 4x6 高密度拼版能在第一代开放的前提，02 报告 v2.0）。
- **两层关系**：第一层解决"放没放对、放没放歪"的**确定性**（防呆），第二层解决"切得准不准"的**精度**（修正）。第一层保证 CIS 每次都能在修正范围内找到标（识别失败率可控），第二层保证找到标之后切得准——缺任何一层，另一层都无法独立兜住体验。

## 3bis. 贴纸版式体系（关键交互设计之一）

### 3bis.1 三层版式模型

| 层级 | 名称 | 说明 | 示例 |
|---|---|---|---|
| L1 | 整版贴纸 | 一张照片 = 一张贴纸（沿照片轮廓留白裁切） | 2x3 整版手帐主贴 |
| L2 | 拼版贴纸 | 一张照片内排布多枚小贴纸（App 自动排版，CIS 对位下高密度可开） | 4x6 上排 12 枚 25mm 圆形头像贴（第一代开放，v2.0） |
| L3 | 自定义轮廓 | 用户指尖在照片上圈画轮廓，主体抠图+沿轮廓切割 | 把宠物从合影里圈出来单独成贴 |
| — | **L3 第一代解锁（v2.0 反转）** | v1.1 曾按模切方案将 L3 延后至二代；方案 C 数控刀头任意走刀 + CIS ±0.1mm 对位下，自定义轮廓的出血区对齐由 CIS 保证，**L3 为第一代首发能力**（刀路通道见 3bis.3） | —— |

### 3bis.2 轮廓库（首发 40+ 模板，云下发）

- 内置分类：圆形/圆角矩形/花边（花形、扇贝边、波浪）、手帐常用（标签、对话气泡、日期框）、方贴（76×76，承载"3x3"需求，见 4.4）、IP 联名（预留运营位，云资源可随时上新）。
- 每个轮廓模板 = 矢量路径 + 安全边距参数 + 建议最小尺寸；渲染时 App 端实时预览切割线（虚线叠加在照片上）。
- **轮廓下发与刀路生成（v2.0）**：预置轮廓走**轮廓 ID**（App 经 Beacon 广播下发，机身参数化生成刀路）；L3 自定义轮廓走**GATT 握手通道下发刀路矢量点集**（点集压缩典型 <2KB、2～5 秒传完，App 显示"正在传输轮廓"；明确不用广播帧分段——广播无链路层重传，丢帧乱序 = 废纸风险，02 报告 v2.0 3.3）。两类轮廓共用 CIS 偏移修正。
- **云下发机制**：轮廓库以资源包形式从米家云端下发（【假设2】），支持运营上新（节日限定轮廓：春节福字边、圣诞花环）——这是低成本持续运营抓手，也是"运营内容"依赖平台侧的点。方案 C 任意走刀下，云上新轮廓**无需任何硬件配套**（模切时代"新轮廓需购新刀盒"的约束解除）。

### 3bis.3 自定义轮廓交互（L3，v2.0 起为第一代首发能力）

- 交互方式：指尖沿主体边缘连点/拖动，App 自动吸附边缘（简化边缘检测算法，端侧运行）；闭合路径后提供"平滑度"滑杆（一键圆滑毛边）。
- **实时估时**：App 按轮廓周长与走刀速度（5～8cm/s）实时估算切割时长并显示（自定义轮廓典型 60～120s，复杂轮廓更长——时长预期管理是 L3 体验的关键，见 6.2）。
- 防呆下限：路径周长/复杂度超限时提示"轮廓过于复杂，切割时间将超过 X 分钟，建议简化"；硬下限：轮廓内最小特征宽度 < 刀头可处理阈值（02 报告 v2.0 定稿后回填）时禁止并提示。
- 出血区处理：自定义轮廓由 App 沿路径自动外扩出血区印刷（CIS 对位保证切割线落在出血带内），用户无需理解出血概念。
- 自定义轮廓可保存为"我的轮廓"，本地保存 + 可选云同步（跨设备使用，【假设2】）。

### 3bis.4 多贴纸拼版（L2）规则

- App 自动排版：用户选 1 张照片 + 轮廓 + 每枚尺寸 → App 在所选相纸规格内自动阵列排布，显示可切枚数。
- **版式能力（v2.0，CIS 对位 ±0.1mm）**：

| 相纸规格 | 第一代开放版式 | 典型切割时长（02 报告 v2.0 估算） |
|---|---|---|
| 2x3（54×86mm） | 25mm 圆 ×4 / 30mm 圆 ×6 / 整版自定义 | 整版 15～25s；拼版 25～40s |
| 3寸（86×102mm） | 25mm 圆 ×9（3×3 阵列）/ 76mm 方贴 ×1 / 拼版混排 | 25～45s |
| 4x6（102×152mm） | **25mm 圆 ×12（全开）** / 30mm×8 / 35mm×6 / 混排 | 整版 45～70s；12 枚拼版 60～90s（12 次抬落刀是大头） |

- v1.1 的密度白名单（4x6 锁 30mm×8 / 35mm×6）随模切方案否决而解除——CIS 对位下 25mm×12 良率可达 99%+（02 报告 v2.0）；二代增量只剩更大画幅、更快走刀与更多轮廓库运营位。
- 支持一图多轮廓混排（比如 6 圆 + 2 矩形）与多照片混排（相册多选后自动分页排版）。
- 拼版时每枚贴纸间保留**隔离切缝**（宽度=刀宽+剥离间隙），保证逐枚揭取不撕连相邻贴纸。
- 每枚轮廓外预留 **≥0.5mm 出血区**（CIS 精度下出血需求从 1mm 收窄；最终值随 02 报告 v2.0 EVT 数据定稿）。
- 出图比例：排版预览所见与打印出图严格 1:1（所见即所切），预览界面叠加显示切割线；**App 按轮廓总长与 5～8cm/s 走刀速度实时估算并显示切割时长**（拼版枚数多时的时长预期管理）。

### 3bis.5 版式推荐逻辑：按"高频方贴"模式做耗材成本引导（v1.1 新增）

**背景（对齐 product-strategist 04 定位分析）**：同为方贴需求，两条打印路径的耗材成本差异显著——3 寸纸（86×102）切单枚 76×76 方贴约 **2.5～3 元/枚**；4x6 纸拼两枚方贴约 **1.3～1.4 元/枚**（单张相纸成本摊薄一半）。用户对此无感知，需要 App 在版式推荐层替用户做成本优化。

**推荐逻辑（写入工作台排版引擎）**：

1. **桌面机（1S，4x6/3寸）用户选方贴需求时**：默认推荐"4x6 拼两枚方贴"版式（标注"约省一半相纸"），次选 3 寸单枚——当次只需 1 枚时仍默认拼两枚（多出的一枚留待下次用，背胶相纸可存放），用户可手动切换。
2. **口袋机（2x3）用户**：无 4x6 通道，默认单枚整版/拼版路线，不展示不可达版式。
3. **识别"高频方贴"模式**：用户连续 2 次以上选择同类方贴版式后，工作台首页将该版式提权为"常用了"快捷入口（免搜索），同时仅在设置页展示成本对比说明（不在主流程弹教育文案，保持"无感知优化"原则）。
4. **透明性兜底**：版式详情页常驻"耗材成本参考"小字（本版式约 X 元/枚，基于当前商城相纸价估算），尊重知情权，不隐藏差异。
5. **原则**：成本引导只做**默认项排序**，永不限制选择权——用户明确选了高成本路径时直接执行，不弹劝阻。

## 4. 端到端用户旅程（步骤级）

> 以下旅程按「首次使用」与「日常主线」分开写；日常主线是评审重点。旅程中用户点按路径用 `›` 表示，App 反馈用【画面】标注，设备动作用【设备】标注。

### 4.1 首次使用（绑定与教学，目标 ≤90 秒完成）

1. 用户购买切割配件，开箱看到：切割机 ×1、可换定位嵌件 ×3（2x3 / 3寸86×102 / 4x6 各一）、规格卡片试用装（每规格 1 张）、贴纸纸包（背胶相纸 10 张装）×1、快速指引卡。
   - 注：用户想要的"3x3 方贴"由 3 寸嵌件上的 76×76 方贴轮廓承载（见 4.4），无需独立的"3x3 嵌件"。
2. 用户打开米家App › 进入自己的**口袋照片打印机**或**照片打印机1S**插件首页。
3. 插件首页顶部横幅（首次出现）："新配件：照片贴纸切割机已发布，把你打印的照片变成贴纸 › 了解"。
   - 【画面】横幅点击进入配件介绍页：15 秒产品动画（打印→插入→按键→揭贴）+ "绑定我的切割机"按钮。
4. 用户点击「绑定我的切割机」。
   - 【画面】扫码引导页：提示"将切割机底部的二维码对准取景框"。
   - 【设备】无动作（绑定前机器保持休眠）。
5. 用户扫描成功。
   - 【画面】"正在连接切割机…请短按切割机侧面按键激活"。用户短按按键，机身 Beacon 开始广播。
   - 【画面】2 秒后显示"绑定成功 ✓"，进入配件设置：机身指示灯绿色常亮 3 秒。
   - 【设备】Beacon 绑定握手完成；此后该配件与本打印机关联。
6. 【画面】三步教学卡片（可跳过）：
   a. "打印时选「贴纸版式」，相纸会自动印上切割辅助定位"；
   b. "打印完成后，连同规格卡片一起插入切割机"（动画演示卡片插入方向）；
   c. "按下切割键，机器自动对位后开始切割，看好进度提示来揭贴"。
7. 首次绑定完成。插件首页新增常驻入口：「制作贴纸」（icon：小刀+照片）。

### 4.2 日常主线（单张照片 → 整版/拼版贴纸，目标全流程 ≤5 分钟）

> 前置状态：用户已绑定切割机；切割机放在打印机旁（同桌面）；手机蓝牙开启。
> **v2.0 时长核算（对 Leader 修订点 6 的确认）**：主线各段 = 选照片/版式 30~60s + 打印 50~60s + 拿纸插入 10~15s + CIS 对位 3~5s + 走刀切割 15~90s（按版式）+ 揭贴 ≈ **2~4 分钟，≤5 分钟目标仍成立**；仅 L3 自定义轮廓叠加圈画编辑（+1~3 分钟）时可能逼近 5 分钟，属用户主动投入的创作时长，不计入"机器等待"。

**第一步：进入功能**

1. 用户打开米家App › 打印机插件首页 › 点「制作贴纸」。
   - 【画面】进入贴纸工作台：上半屏为照片选择区（相册最近照片瀑布流 + 相机入口），下半屏为版式选择区（整版贴纸 / 拼版贴纸 / 自定义轮廓 三个 tab——v2.0 方案 C 下三者第一代全开）。
   - 【设备】无动作。App 后台静默检查切割机 Beacon 是否在广播（不弹任何提示）。

**第二步：选照片与版式**

2. 用户点选一张照片（如：猫的照片）。
   - 【画面】照片进入预览画布，默认套用「圆角矩形」轮廓；画布底部显示当前相纸规格（自动识别当前打印机型号对应规格：口袋打印机 → 2x3，桌面打印机 → 3寸（含"3x3 方贴"版式）或 4x6）。
3. 用户切换到「拼版贴纸」tab，选「圆形 25mm」。
   - 【画面】App 自动排布：2x3 上可切 25mm 圆 ×4 枚；画布显示 4 枚圆形预览（每枚可单独点开微调裁剪窗口）；底部显示"预计切割 25~40 秒"（App 按轮廓总长 × 走刀速度 5~8cm/s 实时估算，见 6.2）。4x6 上可选 25mm×12 高密度拼版（CIS 对位下第一代全开）。
4. 用户点「下一步：打印设置」。
   - 【画面】打印设置页：打印张数（1）、耗材余量提示（"背胶相纸余量：7 张 › 立即购买"）、「打印并切割」主按钮。
   - 【设备】无动作。

**第三步：打印（含切割数据叠加）**

5. 用户点「打印并切割」。
   - 【设备】打印机接收任务（口袋打印机走蓝牙直连；桌面打印机走 WiFi 云/局域网通道，与现有打印任务一致）。同时 App 将本轮版式的**轮廓任务下发给切割机**，机身缓存待命（预置轮廓 = 轮廓 ID，经 Beacon 广播；自定义轮廓 = 刀路矢量点集，经 GATT 握手通道，见 3bis.2）。
   - 【画面】打印进度页（复用现有打印进度 UI）：显示"正在打印贴纸版式…"。打印内容 = 照片拼版图 + **四角打印定位标（CIS 对位的读取对象，一代必需）** + 规格标识暗码（边缘 2mm 印刷条码，人眼不显，供售后诊断）。
   - 【设备】Zink 约 50 秒 / 热升华约 60 秒出纸。出纸完成。
   - 【画面】自动切换到"切割引导"页：动画演示"相纸光面朝上、从进纸口推入到底，插入规格卡片，按下切割键"。附文本："插入后 App 会自动检测，无需返回"。
   - 关键设计：**打印完成 ≠ 任务结束**，App 停留在引导页并后台监听 Beacon 事件，等待用户插入相纸。

**第四步：切割**

6. 用户拿起打印好的贴纸相纸，按动画提示插入切割机（光面朝上、推到底），并插入规格卡片。
   - 【设备】微动开关确认规格编码（如 2x3）；Beacon 广播"纸已插入 + 规格 2x3"事件。
   - 【画面】手机（若仍在引导页）自动跳转切割反馈页："已检测到 2x3 贴纸纸包 ✓"。
   - 若用户已离开 App：本地通知推送"贴纸切割机已就绪，回到米家App查看进度"（可选，见 6.3）。
7. 用户按下切割机上唯一的「切割键」。
   - 【设备】**CIS 对位**：滑架横扫四角标记窗口（各 20×20mm）→ 四标中心解算仿射偏移 → 修正刀路 → 落刀，全程 3～5 秒（02 报告 v2.0）。识别 ≥3/4 标即可继续（App 提示"已用 3 标对位"），<3 标拒绝启动（见 E2-bis）。
   - 【画面】**新增"对位中"状态**（v2.0）：进度环前置一个"正在对位…"阶段（约 3～5 秒），完成后显示"对位完成 ✓ 偏移已自动校正"——让用户感知"机器自己校正了"，这是方案 C 的体验卖点，值得显式呈现而非隐藏。
   - 【设备】**走刀切割**：刀头按修正后刀路走刀，速度 5～8cm/s；时长随轮廓长度：2x3 整版 15～25s、3寸 25～45s、4x6 整版 45～70s、4x6 12 枚拼版 60～90s（12 次抬落刀是大头）、L3 自定义轮廓 60～120s。
   - 【画面】切割进度环：0–100% 按刀路完成度推进（Beacon 状态帧驱动，事件+2s 心跳）；阶段文案随刀路分段变化（"切割外轮廓…/第 n 枚/即将完成"）+ 预计剩余时间（按轮廓长度实时估算）；批量任务显示"第 2/5 张"。
   - 刀路数据来源（v2.0）：App 在打印任务下发的同时下发轮廓任务——预置轮廓 = **轮廓 ID**（Beacon 广播通道），L3 自定义轮廓 = **刀路矢量点集**（GATT 握手通道，见 3bis.2）；两类刀路均叠加 CIS 扫描解算的偏移修正（【假设4】）。
8. 切割完成。
   - 【设备】刀头回零；Beacon 广播完成事件；机身指示灯绿色呼吸。
   - 【画面】完成页：成品示意动画（揭贴演示）+ 两个按钮：「再切一张」（回到照片选择）/「分享」。
   - 用户取纸，逐枚揭下背胶贴纸（隔离切缝保证逐枚可揭）。

**第五步（可选）：耗材闭环**

9. 完成页底部常驻："本次用纸 1 张 · 背胶相纸余 6 张 › 购买"。
   - 【画面】点击直达米家商城对应 SKU（米家生态已有 3 寸背胶相纸商品线，可直接挂靠），支持一键购买。余量低于 3 张时，下次进入工作台顶横幅提醒。

### 4.3 三种相纸规格的处理差异

> v1.1 口径说明：切割机的**物理相纸规格**为 2x3 / 3寸（86×102mm）/ 4x6 三种；用户语言中的"3x3 方贴"由 3 寸纸上的 76×76mm 方贴轮廓 SKU 承载（见 1.2 事实表与 4.4），**不是第四种物理规格**。下表按物理规格组织。

| 环节 | 2x3（口袋打印机） | 3寸 86×102mm（照片打印机1S） | 4x6（照片打印机1S） |
|---|---|---|---|
| 打印设备 | 口袋照片打印机（Zink） | 照片打印机1S（热升华，原生 3 寸） | 照片打印机1S（热升华，6 寸纸） |
| 第一代可切拼版量级 | 25mm 圆 ×4 / 30mm 圆 ×2~3 | 25mm 圆 ×6~8 / **76mm 方贴 ×1（即"3x3 方贴"）** | **30mm 圆 ×8 或 35mm 圆 ×6**（25mm×12 为二代能力，App 端不下发） |
| 版式建议 | 整版/小型拼版/单主体预置轮廓 | 方贴（76×76）、章形贴、手帐拼版 | 大拼版、混排、多照片分页、拼两枚方贴（成本优选，见 3bis.5） |
| 规格卡片 | 2x3 卡片（孔位编码 A） | 3寸卡片（孔位编码 B） | 4x6 卡片（孔位编码 C） |
| 机械嵌件 | 2x3 挡块 | 3寸挡块 | 4x6 挡块 |
| 切割时长（估，走刀 5～8cm/s + CIS 对位 3～5s） | 整版 15～25s；拼版 25～40s | 整版 25～40s；拼版 25～45s | 整版 45～70s；拼版 60～90s（12 枚） |
| 特有异常 | Zink 相纸怕热压（刀头压力参数需按 Zink 特性调低，具体由 hw-engineer 定） | ——（相纸与 4x6 同为热升华材质，刀压参数同 SKU 族） | 热升华相纸厚度更高（刀路深度参数不同；对位冗余区利用热升华高精度优势可更窄） |

### 4.4 "3x3 方贴"的落地路径（v1.1 重审结论）

**v1.0 曾假设 3x3 无在售主机、建议走"4x6 裁切"路径；经核实 1S 原生支持 3 寸打印（86×102mm 背胶相纸官方在售）并与 02 报告交叉裁决后，本节结论已反转：**

- **推荐路径：原生 3 寸规格（1S 打印 + 3 寸嵌件）**。用户要的"3x3 方贴"由 **76×76mm 方贴轮廓**承载：76mm + 2×2mm 出血 = 80mm，宽向 80≤86、长向 80≤102，完整可排布（余边约 6mm/22mm），无需独立"3x3 正方形"物理规格，也无需 4x6 裁切两次。方案 C 数控刀头下方贴轮廓仅为软件版式（无需专属硬件），余下问题只在 3 寸嵌件是否随首发标配。
- **版式语言**：工作台中该版式命名为"方贴（约 3x3）"——用用户语言呈现，详情页标注实际幅面 76×76mm 与所用相纸 3 寸（86×102mm），避免"正方形相纸"的错误预期（画布预览所见即所切，天然消除误解）。
- **旅程差异**：与 4.2 主线**完全一致**——1S 用户选方贴版式 → 放 3 寸相纸打印 → 插 3 寸嵌件切割，无任何额外步骤。原 v1.0 设想的"4x6 相纸打印 3x3 内容 + 先切外框再切内框"两刀路径不再需要（02 报告已按纸面利用率论证否决）。
- **成本提示**：3 寸单枚方贴耗材成本约 2.5～3 元/枚，显著高于 4x6 拼两枚（约 1.3～1.4 元/枚）。App 版式推荐逻辑按 3bis.5 做**耗材成本引导**（桌面机用户高频方贴默认推荐 4x6 拼版路线），但用户明确选择 3 寸单枚时直接执行——体验权与知情权并重。
- **兜底说明**：若产品侧最终决定第一代不做 3 寸嵌件（SKU 精简考虑），"3x3 方贴"需求可临时由 4x6 拼版路径承载（两枚 76×76 方贴 + 中缝），但此为退路而非推荐——终裁权在 product-strategist（04 定位分析）。

### 4.5 多照片/批量场景（次主线）

- 相册多选照片 → 工作台自动分页排版（每页一张相纸）→ 批量打印 → 逐张插入切割（App 逐张显示队列："第 2/5 张，请插入"）。
- 批量时切割队列页显示整体进度条 + 每张缩略图勾选状态，避免用户漏插/重插。

### 4.6 未绑定用户看到的形态（对照组）

- 打印机插件内「制作贴纸」入口灰态显示（半透明 + 锁形 icon），点击后进入配件介绍页（同 4.1 步骤 3），不强弹、不广告化。

### 4.7 异常分支（步骤级）

**E1. 未检测到切割机（Beacon 不在广播）**

- 触发点：用户点「打印并切割」时，App 检查 Beacon 无响应。
- 【画面】底部弹层（非阻断）："未找到切割机。仍可打印贴纸版式，稍后手动切割或定位后再切 › 去检查"。
- 行为：允许打印（版式与定位标照常打印，保证打印任务不浪费）；「去检查」展开清单：短按切割机按键唤醒 / 确认电池有电 / 查看帮助。
- 手动兜底：若始终无 Beacon，用户可全程用机身按键操作（插入→按键→切），App 只是不显示进度与不下发自定义轮廓；预置轮廓任务在机身缓存或上轮下发的残留中时切割结果不受影响。**这是"从属配件"形态的兜底哲学：App 缺席时基础功能不残废**（注：v2.0 方案 C 下，首次使用仍需 App 完成绑定与至少一次任务下发，完全无 App 的裸机体验弱于模切方案，属形态代价之一）。

**E2. 放错方向（相纸反插）**

- 触发点：相纸光面朝下插入。
- 机制：机械防呆——进纸口挡块形状与相纸定位缺口非对称设计，反向物理插不进（第一道防线）；若用户用力强行插入（第二道防线），CIS 扫描不到定位标 → 按无标处理（E8/E2-bis 路径）。
- 【画面】"相纸方向反了。请光面朝上重新插入" + 3 帧动画。机身指示灯橙色快闪。
- 关键点：**此异常被机械设计消解为低频事件**，交互只做兜底。

**E2-bis. CIS 对位失败（定位标识别不足）**

- 触发点：定位标被指纹污损/反光遮挡/打印过淡，识别 <3/4 标。
- 【设备】**拒绝启动**（不降级机械对位——02 报告 v2.0：参数化任意刀路对安全余量要求高，机械对位 ±0.3～0.5mm 不足以兜住任意轮廓，降级 = 产生不合格品，宁可拒绝）；Beacon 上报"对位失败"事件码。
- 【画面】"对位失败：定位标不清晰。请用软布轻拭相纸四角标记后重新插入 › 查看图示" + 动画（标出四角位置）。
- 分级呈现：≥3/4 标识别成功时**不报错**，正常切割，完成后进度页小字提示"本次使用 3 标对位"（透明但不打扰）。
- 兜底：擦拭重插 2 次仍失败 → 引导"重新打印本张"（App 保存版式任务，一键重打，耗材计数不补偿——打印内容本身没问题属于相纸污损范畴；连续 2 张出现此问题则提示检查打印机打印浓度设置）。

**E3. 走刀中断 / 卡纸（断点续切）**

- 触发点：走刀负载异常（刀头卡滞）、相纸移位、意外断电。
- 【设备】立即停刀 → **刀头抬 Z 至安全高** → MCU 将刀路指针 + XY 坐标掉电记录至 Flash（02 报告 v2.0）；Beacon 上报中断事件码；机身指示灯红色常亮。
- 【画面】"切割已暂停。请打开上盖排除障碍（异物/翘边），完成后合盖 › 查看图示"。
- **恢复流程（需用户确认，非全自动）**：
  1. 用户排除障碍、合盖后**按切割键确认**；
  2. 【设备】刀头自动回零 → 跳至断点前 2～3mm 重叠量续切（保证接缝质量）；
  3. 【设备】续切前 **CIS 复核纸位**——比对当前定位标坐标与中断前记录：
     - 偏移在阈值内 → 自动续切完成，【画面】"已从断点继续 ✓"；
     - 偏移超阈值（纸被重放过）→ 拒绝续切，【画面】"纸张已移动，断点续切可能错位。建议取出重新切割本张 › 重切"（此时取出重切 = 整张重切，废 1 张）；
     - 复核通过且剩余刀路走完 → 完成，进入完成页。
- 兜底：若同一张中断 ≥2 次 → 引导"跳过本张"（App 标记报废，耗材计数+1，弹耗材补偿券——负体验的耗材兜底是贴纸用户口碑关键）。
- 交互原则：**断点是机器的事，确认是用户的事**——恢复永远显式按键确认，不自动重启走刀（安全优先，儿童场景下尤其重要）。

**E4. 放错规格（相纸/规格卡片/嵌件不匹配）**

- 触发点：用户把 2x3 相纸放进 4x6 嵌件，或插错规格卡片。
- 机制：嵌件内挡块对 2x3 相纸无约束（会松动）→ 位置传感器检测相纸实际尺寸与卡片申报规格不符 → 拒绝启动；App 下发任务中的规格参数与机械识别结果由机身固件比对，不符时报错（方案 C 无刀盒，v1.1 的刀盒校验已随模切方案删除）。
- 【画面】"检测到的是 2x3 相纸，但当前装的是 4x6 卡片。请更换规格卡片（机身侧面插槽）或更换对应嵌件" + 动画。
- 防呆设计目标：用户最多试错一次即可理解"卡片/嵌件/相纸三者要对齐"。

**E4-bis. 刀片磨损/到寿提示**

- 触发点：累计走刀里程接近标称寿命——**1 年 / 500 米累计刀路，以先到者为准**（02 报告 v2.0 6.4：刻字机碳钨钢刀典型 1000～3000 米，家用单张 0.3～1 米 × 年 1800 张，取保守值；刀尖应力集中+反复抬落刀，寿命天然短于模切整体刀模）。计数在机身 MCU，**更换刀片时配复位**（新刀片 cartridge 插入自动清零）。
- 【画面】配件设置页与工作台顶部横幅分级提示："刀片即将需要更换（剩余约 X 米）› 购买刀片"；到寿后**不强制停用**，但切口质量（毛边率）可能下降，提示明示"建议尽快更换以保持切口质量"。
- 购买路径：横幅 › 米家商城刀片 SKU › 一键购买。**刀片为独立耗材 SKU（cartridge 化全包覆换刀，用户不触裸刀）**：建议单片 ¥19～29、双片装 ¥29～39（02 报告 v2.0 6.4）——与相纸构成双耗材线，商业模型由 product-strategist 论证（开放问题 8）。

**E5. 打印与切割断联（打印完成后用户离开、App 被杀）**

- 行为：切割机独立可完成切割（刀路自持），App 缺席不影响结果；用户返回 App 时，工作台显示"上次任务已完成 ✓ 查看记录"。
- 记录页：时间、照片缩略图、规格、枚数；支持"再切一次"（重新打印同版式）。

**E6. 耗材耗尽（打印前）**

- 触发点：打印设置页检测余量 0。
- 【画面】"背胶相纸已用完 › 去购买"，主按钮从「打印并切割」变为「去购买」；不可继续打印贴纸版式（普通打印不受影响）。
- 打印中途纸尽沿用打印机现有交互（口袋/桌面打印机已有缺纸提示逻辑，不重复设计）。

**E7. 切割机固件升级**

- 触发点：轮廓库/刀路协议更新。
- 【画面】工作台进入时静默检查，若有新版本：顶部横幅"切割机有新功能（新轮廓模板 ×8）› 更新"。点击后经 Beacon OTA（【假设4】）或引导"将切割机 USB 连接手机"后更新；进度条 1–2 分钟。
- 原则：**永不强制升级**，不阻断主线。

**E8. 非贴纸相纸（普通相纸）误插入切割机**

- 机制：普通相纸无定位标印刷 → CIS 扫描四角无标 → 拒绝启动（与 E2-bis"有标但识别不足"区分：无标 = 非贴纸版式，有标但 <3 = 污损）。
- 【画面】"这张相纸不是贴纸版式打印的。请在「制作贴纸」中打印后再切割 › 去制作"。
- 附注：考虑"普通照片切白边"作为隐藏彩蛋功能（长按切割键进入"自由切"模式，跳过 CIS 对位直接按嵌件尺寸切外框）——给进阶用户留口子，不在主线宣传；方案 C 任意走刀下此彩蛋技术上顺带支持（外框为矩形刀路），是否开放取决于安全评估（开放问题 5）。

## 5. 与现有打印机插件的关系

### 5.1 方案对比

| 维度 | 方案甲：现有插件功能增强（推荐） | 方案乙：独立"米家贴纸工坊"插件 |
|---|---|---|
| 入口路径 | 打印机插件 › 制作贴纸（1 次点击） | 米家App首页新设备卡 → 新插件（2 次点击 + 设备认知） |
| 用户心智 | "打印机的新玩法"，与已有打印习惯连续 | "新设备新App"，产生学习成本与割裂感 |
| 开发成本 | 现有打印机插件升级（两个插件：口袋版/桌面版，可共用贴纸工作台组件） | 新插件从 0 开发 + 新设备模型认证 + 插件审核 |
| 相册/照片能力复用 | 直接复用现有插件的照片选择、编辑、打印队列、进度 UI | 需重建或桥接 |
| 对未购买配件用户的影响 | 无感（入口灰态/引导态，不打扰） | 无（不显示）但营销触达缺一条自然路径 |
| 双设备任务串联 | 天然支持（打印→切割在同一插件内状态机串联） | 需跨插件跳转或云消息桥接，体验断层 |
| 风险 | 插件体积膨胀（可控：贴纸工作台做成可下载动态模块【假设5】）；若未来切割机独立销售给非米家打印机用户则受限 | 无此限制，但与当前"配件"定位矛盾 |

### 5.2 推荐：方案甲（现有插件功能增强），理由：

1. **旅程连续性是本产品体验的生命线**（4.2 的主线靠同插件内状态机串联；跨插件会打断"打印完成→插入切割"的引导流）。
2. **低成本快上线**：无需新设备模型认证，插件升级走既有迭代通道，上市周期短——与"低价配件快速试水"的商业节奏匹配（与 product-strategist 的结论对齐）。
3. **插件膨胀风险可控**：贴纸工作台设计为动态下发模块（首用时下载，约 20–40MB），未用用户零负担（【假设5】需平台确认插件动态模块能力）。
4. **独立插件的唯一优势**（服务非米家打印机用户）与第一代"纯配件"定位矛盾；若未来出独立版切割机，再拆独立插件不迟。

打印机插件首页新增（口袋版与桌面版同步）：

## 6. 关键交互设计详述

### 6.1 贴纸版式交互（见 3bis）

要点重申：三层版式模型（整版/拼版/自定义，**三者第一代全开**——v2.0 方案 C + CIS 下 L3 为首发能力）；轮廓库云下发持续运营（云上新轮廓无需硬件配套）；拼版自动排版 + 隔离切缝 + ≥0.5mm 出血区 + 实时切割估时；所见即所切（预览叠切割虚线）。

### 6.2 切割进度反馈

- 进度来源：Beacon 状态帧（状态码：就绪 / **对位中（v2.0 新增）** / 切割中 / 暂停（断点）/ 完成 / 错误 + 刀路完成度百分比 + 当前张次），事件驱动 + 2 秒心跳（【假设4】，帧率与带宽需协议评审）。
- **"对位中"状态（v2.0）**：按键后 3～5 秒的 CIS 扫描解算阶段，进度页显示"正在对位…→ 对位完成 ✓ 偏移已自动校正"——方案 C 的核心体验卖点之一（用户感知"机器自己校正了"），显式呈现而非隐藏；3 标降级对位时加小字提示。
- **切割中进度**：走刀时长显著长于模切（15～120s 量级），连续百分比进度环有了真实意义——按刀路完成度推进（Beacon 帧驱动），阶段文案（"外轮廓…/第 n 枚/即将完成"）+ 按轮廓长度实时估算的剩余时间；批量任务叠加"第 2/5 张"张次计数。
- 长任务预期管理：进入切割前，App 已按轮廓长度预估并显示时长（3bis.3/3bis.4）；L3 自定义轮廓与 12 枚拼版（60～120s）时，进度页提供"切完提醒我"开关（完成后本地通知，用户可离开做别的事）。
- 机身侧：指示灯阶段色（待纸=蓝、对位中=紫、切割中=青色呼吸、完成=绿色呼吸、暂停=橙闪、异常=红）；完成时可选短促提示音（默认关，设置可开）。
- 防呆：进度页显示"请勿在切割中开盖"顶部常驻提示（上盖安全开关为硬件级断电，开盖即停即断点，见 E3）。

### 6.3 通知与提醒策略（克制原则）

- 切割就绪但用户不在 App：仅当用户"已开始打印贴纸任务但 3 分钟未插入"时，发一条本地通知（不推送、不短信）。
- 完成：单张短任务不通知（用户大概率就在机器旁）；批量任务（≥5 张）完成时通知一次；**开启"切完提醒我"的长任务（L3/12 枚拼版，60s+）完成时通知**（v2.0 新增，见 6.2）。
- 耗材余量：≤3 张时下次进入工作台横幅提醒；0 张时阻断打印贴纸任务（E6）。
- 所有通知默认可在配件设置中关闭。

### 6.4 耗材（背胶相纸）提示与购买引导

- 计数机制：打印贴纸版式时按张数累计扣减（App 端估算），支持用户在配件设置中「重置计数」（换新纸包时手动重置，或扫描纸包内附二维码自动重置——纸包二维码承载"规格+张数"，扫描即校准余量，同时是规格识别的数字孪生）。
- 购买路径：工作台打印设置页 › 米家商城 SKU › 一键购买（米家生态已有 3 寸背胶相纸在售商品线，供应链与合规先例成立）。
- 首次购买引导：耗材余量首次 ≤3 张时，横幅附"首次购买立减"券（商业化细节与 product-strategist 对齐）。
- 纸包二维码设计：编码规格（2x3 / 3寸86×102 / 4x6）+ 张数 + 批次（批次用于质量追溯与刀压参数微调——不同批次背胶厚度差异可下发补偿参数，云下发通道同轮廓库【假设2】；刀压按 SKU 族配置，见 02 报告 1.2）。

### 6.5 视觉与文案基调

- 延续米家插件白底卡片式设计语言；贴纸工作台允许更高饱和度的内容色（贴纸主题本身多彩）。
- 文案口语化、动词开头："切一张试试""揭下来，贴上去"。
- 旅程中的关键节点用插画而非照片示意（首次教学 3 卡片、异常动画），保持米家 App 一贯的克制风格。

## 9. 开放问题（提请团队研讨）

1. ~~**刀路数据通道**~~ **已两轮裁决**：v1.1 定 Beacon 轮廓 ID（模切基线）；v2.0 方案 C 下升级为"预置轮廓 = Beacon 轮廓 ID + L3 刀路矢量点集经 GATT 握手通道下发"（02 报告 v2.0 3.3），本报告 3bis.2/4.2/7.1 已按此更新。
2. ~~**3x3 规格落地路径**~~ **已收敛（待商业终裁）**：核实 1S 原生支持 3 寸打印（86×102mm 背胶相纸在售），推荐路径为"原生 3 寸 + 76×76 方贴轮廓"（4.4）。遗留 product-strategist 从 SKU/成本角度终裁（含"第一代是否精简掉 3 寸嵌件"的退路评估）。
3. ~~**自定义轮廓的第一代边界**~~ **已反转（v2.0）**：方案 C 数控刀头 + CIS ±0.1mm 下，L3 自定义轮廓为**第一代首发能力**（出血区对齐由 CIS 保证，良率 ≥98%，02 报告 v2.0 3.2），v1.1 的"第一代隐藏"限制解除。
4. **耗材计数精度**：App 估算 vs 纸包二维码校准的混合方案，其误差是否可接受——建议小样本用户测试。
5. **E8 彩蛋"自由切模式"**：是否随第一代发布（方案 C 下技术顺带支持，纯安全/法务评估：无 CIS 对位切割的安全边界）。
6. **3bis.5 耗材成本引导的度量**：默认推荐切换后 4x6 拼两枚方贴的采纳率、以及用户手动改回 3 寸单枚的比例——上线后 A/B 观测，防止"过度替用户做主"的反噬。
7. **（v2.0 新增）L3 端侧抠图算法的成品率**：CIS 保证"切得准"之后，剩余风险在"圈得准不准"（用户指尖圈画 + 边缘吸附算法的抠图质量）；建议 EVT 阶段做真机用户测试，抠图失败时引导回退预置轮廓。
8. **（v2.0 新增）刀片耗材的商业口径**：寿命 1 年/500 米（先到为准）、SKU ¥19～29 的定价与"到寿不强停"策略是否成立（E4-bis），需 product-strategist 纳入耗材商业模型（与相纸双耗材线）。
