Phase 0a · 推荐

活动现场场景

漫展 / 快闪摊位。摊位屏出二维码，观众扫码进入手机流程：模拟微信授权（获客+1）→ 选预设设计 → 选份数 → 模拟支付 → 拿到取件码。工作人员在控制台接单、选设备制作，完成后手机收到「可取货」推送，摊位屏叫号。

Phase 0b · 复用同一套管道

常规线上场景

与活动场景共用同一状态机、同一张订单表、同一条管道（差异仅参数：无现场排队叫号，自提/快递交付）。当前演示聚焦活动场景闭环，常规场景复用本管道，见文档 FULFILLMENT-PRD.md §1.1。
