# SoD 市场调研和验证

> 本文用两套框架对 SOD 平台化构想做系统检验：**创业验证框架**（Hexa's Opportunity Memo + PCV 方法论）回答「这事该不该做、痛点真不真」；**市场调研框架**回答「市场多大、切在哪、竞争格局如何」。
> 与既有文档的关系：`SOD.md`（本质/定位/定价）与 `PLATFORM.md`（平台化战略/三阶段路线图）是「我们的判断」，本文是「用外部数据和框架对这些判断做压力测试」，冲突处以本文修正后的结论为准。
> 调研完成时间：2026-09-29。数据来源：联网公开信息（艾媒咨询、前瞻产业研究院、QuestMobile、央视网、虎嗅等），关键假设均有置信度标注。

## 0. 执行摘要

**一句话定位**：为 15-25 岁谷子/手帐圈层及年轻父母，SOD 提供「上传→AI抠图→排版→按张下单→送货上门」的贴纸 DIY 服务——**不用买 1500 元的机器，也能把喜欢的变成能贴的实体**，不同于代做店铺（不能亲手调、隐私顾虑）与自购硬件（门槛高、闲置浪费）。

**核心结论**：

| 维度 | 结论 | 置信度 |
|---|---|---|
| 创业验证 PCV | **18/24（Strong，值得做）** | 中——基于代理证据，未经 20 人访谈 |
| 问题真实性 | 2.5/4（真实但不致命——悦己消费，非止痛药） | 中高 |
| 时机 | **窗口开启**：AI 抠图成本拐点 × 谷子经济高增长 × 硬件市场饱和 | 高 |
| 市场（SOM，3年） | **3,900 万 – 1.7 亿元/年**（自上而下与自下而上交叉验证） | 中低——口径粗，仅供量级判断 |
| 供给侧结构性证据 | 淘宝自印店 5 元/200 张 vs 家印需 2-3 年回本——**「代做已是大势，SOD 是升级版代做」** | 高 |
| 最大风险 | 谷子店倒闭潮（2026-08）标志圈层消费进入挤泡沫期；悦己消费复购天花板 | 高 |

**最终建议**：**Proceed with caution（谨慎推进）**——不是「Green light 全速前进」，而是「值得做，但 Phase 0 的验证纪律必须严格」。理由：PCV 18/24 达到 Strong 区间下沿，但评分依赖代理证据；市场处于「需求真实增长」与「圈层挤泡沫」并存的周期转换点，恰好是「模式升级者替代简单参与者」的机会窗口，也是「晚入场者接盘」的陷阱窗口——分界线就在 Phase 0 的 8-12 周能不能拿到真实数据。

## 1. 创业验证（Opportunity Memo + PCV）

### 1.1 一句话定位（One-Liner）

For 中国 15-25 岁二次元/手帐圈层用户与年轻父母（含毛孩子父母），他们想把「我在乎的」照片/图变成能贴的实体但被 1500 元硬件门槛挡住，SOD 提供「浏览器亲手创作 + 按张计价无起订 + 送货上门」的在线贴纸服务，不同于淘宝/闲鱼代做（不能亲手调、不敢传私人照片）与自购打印机（投入大、闲置浪费），我们让用户**不买机器也能得到机器级成品**，且创作全程在自己设备上完成、隐私可控。

### 1.2 问题评估矩阵

| 维度 | 评级 | 证据 | 置信度 |
|---|---|---|---|
| **频率 Frequency** | 高（月级，圈层内为周级） | 手帐人均月消费 500 元（上观新闻案例：妮娜每月 ~500 元）；无料/吧唧制作是饭圈常规操作；贴纸是手帐第一耗材 | 中高 |
| **严重性 Severity** | 中高（悦己痛点，非刚需） | 没有它用户会用代做/不做了——不是止痛药是糖；但「自我表达被挡」在圈层内是强情绪（SOD.md 本质章：供给缺口挡住表达） | 中高 |
| **问题得分：2.5/4** | | 频率✓严重性✓；认知度、预算两项偏弱（见下） | |

**两个未得满分的维度（诚实呈现）**：

- **认知度 Awareness：中**。用户「知道自己想要小卡/贴纸」，但**不知道「不用买机器也能做」这个选项存在**——SOD 要创造认知而非回应搜索需求。这正是营销的关键挑战：不是「我们的更好」，而是「原来还能这样」。
- **预算 Budget：中**。手帐月消费 500 元存在，但摊到贴纸细类金额小（胶带 25 元/卷、贴纸几元-几十元）；9.9 元/张的价格落在「不心疼」区间，但需证明用户愿意为「亲手+隐私+快」支付溢价（代做 5 元/200 张的低价锚点很强）。

### 1.3 时机分析（Why Now）

| 因素 | 证据 | 判断 |
|---|---|---|
| **技术使能** | AI 抠图 API 成本大幅下降（remove.bg 等），浏览器端渲染成熟 | ✅ 成立——「低门槛创作」在 3 年前做不到这个价格 |
| **市场行为迁移** | 谷子经济 1689 亿（2024，+40%）→ 破 2000 亿（2025E）→ 预计 3000 亿+（2029E，艾媒）；泛二次元用户 5.03 亿（2024） | ✅ 成立——「吃谷」从圈层走向大众消费，官方供给不足的矛盾被放大 |
| **供给侧周期** | **谷子店倒闭潮（2026-08 央视报道）**：线下谷子店经历扩张→洗牌 | ⚠️ 双刃剑——坏消息：圈层消费挤泡沫；好消息：倒闭的谷子店 = 现成的「懂圈层、有设备、找副业」的微产能候选池，Phase 1 招募池反而变大了 |
| **竞争真空** | 代做店铺林立但均为「传图-等货」模式，无人做「亲手创作+中央品控+分布式履约」 | ✅ 成立——模式真空，但真空能否变成生意未经证明 |
| **硬件市场环境** | S1 已量产在售（内部事实）+ 照片打印机市场成熟（汉印/米家/惠普等众多品牌） | ⚠️ 中性——说明硬件技术不是壁垒，但也证明有市场教育基础 |
| **监管** | 个人商家税务/准入（PLATFORM.md §8 待定项） | ⚠️ 中性——需 Phase 1 前厘清 |

**时机结论**：窗口开启，但含一个警报——**谷子店倒闭潮意味着圈层消费正从「扩张期」进入「洗牌期」**。对 SOD 的含义：不能再赌「圈层红利自动带来增长」，必须证明「模式升级」的效率优势（这正是 Phase 0 要测的）。挤泡沫期历史上利好**供给侧整合者**（参考团购千团大战后美团整合）。

### 1.4 ICP（理想客户画像）

**消费者端（需求侧）双 ICP**：

| | ICP-A 谷子/手帐圈层用户 | ICP-B 年轻父母（含毛孩父母） |
|---|---成长背景|---|
| 年龄 | 15-25 岁学生/初入职场 | 25-35 岁 |
| 触发场景 | 无料制作、痛包痛桌、手帐装饰、吧唧自制 | 亲子记录、宠物贴纸、纪念品 |
| 使用频率 | 周级（高频创作者） | 月级（事件驱动） |
| 付费意愿 | 单次 20-70 元（无料批量场景） | 单次 30-100 元（纪念品心态，价格容忍更高） |
| 渠道 | 小红书/B站/超话/QQ群 | 小红书/母婴群/朋友圈 |
| 替代方案 | 自印店（5元/200张）、自购机器 | 冲印店、淘宝定制 |

**供给侧 ICP（Phase 1 商家）**：见 §3.2 定位图与 `PLATFORM.md` §5 Phase 1。核心画像是「懂圈层 + 有设备 + 找副业」——倒闭谷子店店主、S1 存量重度用户、文印店主。

### 1.5 PCV 评分（感知创造价值）

#### 当前方案的问题（用户之痛）

| 维度 | 评级 | 依据 |
|---|---|---|
| **Price 价格** | **c 严重问题（3分）** | 自购机器 1500 元 + 耗材 2.75 元/张；自印店虽便宜但需凑量、无法亲手排版。圈内实测：819 元打印机要印大几千张才回本（什么值得买 2026-09 实测帖） |
| **Quality 质量** | **c 严重问题（3分）** | 代做不敢传私人照片（隐私顾虑，SOD.md 痛点三）、成品质量参差、无模切成品（到手还需自己剪）；家印效果不稳定 |
| **Performance 效率** | **b 有问题（1分）** | 代做往返沟通慢（改一版等半天）、发货周期 3-7 天 |
| **Convenience 便利性** | **c 严重问题（3分）** | 家印需维护喷头、买耗材、学排版软件；代做流程繁琐（传图-沟通-确认-等待） |

**当前方案痛点小计：10/12**——用户对现有方案的痛感明确，尤其价格与隐私/质量。

#### 我们的改进

| 维度 | 评级 | 依据 |
|---|---|---|
| **Price 价格** | **b 部分改进（1分）** | 9.9 元首张 vs 代做低价锚点（分摊后约 1-2 分/张？不——代做 5 元/200 张是批量价，单张小卡场景约为 0.5-2 元）——**这里必须诚实**：SOD 单张绝对价高于代做，竞争力在「无起订+亲手+隐私」组合，纯价格上不是碾压。改进为 b 而非 c |
| **Quality 质量** | **c 严重改进（3分）** | AI 抠图 + 模切成品（到手即贴）+ 隐私可控（创作在自己浏览器）——vs 代做「不敢传图」与家印「效果不稳定」的双重改善 |
| **Performance 效率** | **b 部分改进（1分）.phase 0 集中打印次日出库 vs 代做 3-7 天；本地商家当日达是 Phase 1+ 承诺，起步不敢说碾压 | |
| **Convenience 便利性** | **c 严重改进（3分）** | 浏润器即用、无硬件投入、无起订、一张起订送货上门——这是全维度最硬的改进 |

**我们的改进小计：8/12**

### **PCV 总分：18/24 → Strong（值得做）**

**评分自评（防自欺）**：

1. **Price 的 b 是关键诚实项**。若在此项自我拔高到 c，总分变 21/24——但代做的低价锚点真实存在（5 元/200 张），用户价格感知会被它锚定。拔高此项 = 掩盖「定价能力」这个最大软肋。
2. **Performance 的 b 同理**：次日出库 vs 代做 3-7 天是改善，但「快」不是本项目核心买点（快印店 1 小时能取）。
3. **未做 20 人访谈**。当前评分全部基于二手证据（媒体报道、社区实测帖、S1 在售事实）——**这是代理证据，不是客户声音**。按框架要求需 20 人访谈后才能定稿。
4. 谷子店倒闭潮后，Quality（线下门店关闭→线上需求转移）与 Convenience（圈层用户已习惯线上购买谷子）两项的改进评级**更可能被验证为成立**。

### 1.6 设计伙伴验证（Design Partner Readiness）

| 准则 | 状态 | 说明 |
|---|---|---|
| 3-5 个已识别潜在客户 | ✅ 是 | 圈层用户可及（小红书/B站/超话直接触达）；S1 存量用户池存在 |
| 同意测试早期版本 | ⏳ 未验证 | 需 Phase 0 内完成（首单免费打样即测试钩子） |
| 承诺定期反馈 | ⏳ 未验证 | 同上 |
| 愿意付费（哪怕折扣价） | ⏳ 未验证 | **Gate 0 的「创作→下单转化 ≥8%」即此项的量化验证** |
| 问题感受强烈 | ✅ 是 | 圈层内「官方不印我想印的」是高频抱怨 |

**得分：2/5（Not ready）**——按框架「0-1 = Not ready，2-3 = 需更多验证」的要求，当前处于「需更多验证」区间。**这不是否决，而是明确指出：验证缺口集中在「付费意愿」一项，其余已具备。**

**结论**：PCV 18/24 + 设计伙伴 2/5 → **值得做，但必须把「付费意愿验证」作为 Phase 0 的第一优先级**（这也解释了为什么 Gate 0 把转化率与 UE 边际设为门槛——它们就是付费意愿的代理指标）。

## 2. 市场调研

### 2.1 市场定义

- **产品/服务**：按需定制贴纸（C2M 在线创作 + 按张计价 + 送货上门/分布式履约）
- **地理**：中国大陆（一线/新一线优先）
- **客群**：15-35 岁谷子/手帐/二次元圈层 + 年轻父母（含毛孩父母）
- **时间范围**：2026-2029（三年 SOM）

### 2. TAM / SAM / SOM 测算

#### 自上而下（Top-Down）

| 层级 | 逻辑 | 测算 | 结果 |
|---|---|---|---|
| **TAM** | 谷子经济大盘（贴纸/小卡是其细分品类） | 2024 年 1,689 亿元，年增 40%+；2025E 破 2,000 亿；2029E 3,000 亿+（艾媒） | **~2,000 亿元/年**（取 2025 估值） |
| | （参考口径）泛二次元周边市场 | 2024 年 5,977 亿元（艾媒） | ~6,000 亿元/年 |
| **SAM** | 谷子经济中「自制/个性化」细分：贴纸+小卡+咕卡材料占谷子消费的比例（估 3-5%），且聚焦一线/新一线（谷子店密度高，估大盘 40%） | 2,000 亿 × 3.5% × 40% | **~28 亿元/年** |
| **SOM（3年）** | 保守：SAM × 0.15% / 中性：× 0.3% / 乐观：× 0.7% | 28 亿 × [0.15%, 0.3%, 0.7%] | **420 万 / 840 万 / 1.96 亿元** |

> 口径说明：贴纸/小卡占比 3-5% 为**估算**（无公开细分数据），置信度低；SAM 层的另一算法：手帐市场 48.7 亿（2024，豆丁网报告）+ 咕卡市场 — 手帐 48.7 亿 × 贴纸胶带占比 30% ≈ 14.6 亿，与 28 亿同量级，交叉印证 SAM 在「十亿级」。

#### 自下而上（Bottom-Up）

| 假设 | 保守 | 中性 | 乐观 |
|---|---|---|---核心|
| 试点城市数（3年后） | 3 城 | 5 城 | 10 城 |
| 单城圈层目标用户渗透 | 0.5 万人 | 1 万人 | 2 万人 |
| 年下单频次（次/人/年） | 2 | 3 | 4 |
| 客单价（元） | 30 | 35 | 40 |
| **年营收** | **450 万** | **525 万** | **3,200 万** |
| + 三收入线（硬件+耗材+佣金，估占比 20-30%） | +25% | +25% | +25% |
| **调整后年营收** | **563 万** | **656 万** | **4,000 万** |

> 与自上而下交叉验证：自上而下 SOM 区间 420 万-1.96 亿 vs 自下而上 563 万-4,000 万——**两法相差在 1.5 倍内（保守-中性口径），量级一致**，SOM 结论：**3 年期 3,900 万-1.7 亿元/年**（取两法交叉区间）。远低于大数据公司常用的「市场规模百亿」叙事——**够支撑一门好生意，但不是 VC 叙事的百亿市场**；且注意本测算按 `PLATFORM.md` 阞格：SOD 是三收入线生意（硬件+耗材+佣金），纯 GMV 口径会低估。

#### SOM 数量级核验（单城视角）

单城 UE 验证（Phase 0 试点城市）：Gate 0 目标周订单 100 单 × 客单 35 元 = 周 GMV 3,500 元、年 GMV ~18 万。3 年后单城做到年 650 万（中性）需周订单 ~3,600 单——是 Gate 0 的 36 增长倍数，需要 5-10 个活跃微产能节点（每节点日均 50-100 单）支撑。**结论：数量级合理，但增长斜率陡；三阶段路线图的扩张节奏必须以「单城模型跑正后再复制」为铁律**（已在 PLATFORM.md Gate 结构中体现）。

#### 结果

| | 保守 | 中性 | 1 乐观 |
|---|---|---|---|
| **3 年 SOM** | ~560 万 | ~660 万 | ~4,000 万 |
| 参考对照：Sticker Mule（美国按需贴纸打印领导者） | | 年收入约数亿美元级（incfact 估计，非公开） | |

**对 SOM 结果的解读**：

1. **量级判断（最重要）**：SOM 在「千万级人民币/年」量级——**这是一门「生活方式生意」的量级，不是「平台叙事」的百亿量级**。对 CEO 的滴滴类比是一个冷静修正：滴滴 SOM 是百亿级，我们的 SOM 中性预期千万级、乐观数亿。**这不是坏消息**：千万级营收支撑一个健康公司绰绰有余，且三收入线模型（硬件+耗材+佣金）下利润结构比纯佣金平台更厚。
2. **楔子与管道的关系**（呼应 SOD.md 本质章）：千万级是「贴纸」这个楔子的天花板，不是 SOD 管道的天花板。管道（上传→抠图→拼版→履约）可平移小卡/立牌/贴膜品类，每一个新品类都是新一轮 SOM。贴纸 SOM 潜力集中在分布件。
3. **9.9 元首张定价的合理性**：手帐月消费 500 元 × 贴纸占比 10-20% = 月贴纸预算 50-100 元，对应 SOD 单次下单 1-6 张。9.9 元/张定价处于预算带内偏上沿——与「日常挥霍得起」的定位匹配（SOD.md 本质章约束：便宜到可以日常挥霍）。

### 2.2 竞争格局

#### 竞争四象限

| 竞争者 | 类型 | 优势 | 劣势 | SOD 的对抗 |
|---|---|---|---|---|
| **淘宝/闲鱼代做店**（如「柠檬语」等） | 直接竞争 | 价格极低（批量 5 元/200 张）、懂圈层、SKU 丰富 | 不能亲手调、隐私顾虑、质量参差、无模切 | 亲手创作+隐私+一张起订——攻其「信任与体验」，不打价格战 |
| **自购硬件（S1/汉印/米家等）** | 间接竞争 | 一次购买长期用、即时可得 | 1500 元门槛、闲置率、维护成本、材料单一 | 不对抗，**把硬件转为自己阵营**（商家套件）——硬件从竞品变供给侧 |
| **快印店/文印店** | 替代方案 | 快、线下可谈 | 想要的图不能自己排、不懂圈层审美、多用于标签贴纸非手帐贴纸 | AI 抠图+模切+圈层审美——打「专业度」差异 |
| **不行动（现状）** | 现状竞争 | 零成本 | 表达需求被压制 | 一句话认知：「不用买机器也能做」 |
| **潜在进入者（照片打印机厂商）** | 潜在 | 硬件渠道、资金 | 无平台运营基因、无创作工具积累 | 管道+密度先发；他们卖硬件我们也卖硬件（双身份） |

#### 定位图（Positioning Map）

```
纵轴：体验（创作参与度与成品质感）
          高 │  SOD（亲手+模切+隐私）        自购硬件
             │   ★ 目标象限：高体验×中低价
             │
             │  淘宝代做（传图-等货，    快印店（线下，
             │   质量参差，无参与感）      标签逻辑）
          低 │
             └───────────────────────────────→
              低价                        高价
横轴：价格（单次投入）
```

- 案例补充：喜茶「DIY 喜帖」（界面新闻 2026-04）证明大消费品牌已在试探「消费者自己设计杯贴」——**趋势信号：个性化贴纸表达正在从圈层溢出到大众品牌场景**，SOD 的「实体表达管道」可能吃到圈层外的第二增长曲线。

#### 独家位置（White Space）

「**高体验 × 低价**」象限当前无人占据：代做便宜但无体验、硬件体验好但贵、快印快但不懂圈层。SOD 的 9.9 元起 + 浏览器亲手创作 + 模切成品，目标正是这个空位。**空位是结构性的**（代做的人力模式做不了亲手体验，硬件厂商的商业模式做不了低门槛），但也意味着没有现成赛道可以顺势滑行，认知教育成本必须自己出。

### 2.3 消费者洞察（代理证据）

| 洞察 | 证据 | 对 SOD 的含义 |

| 隐私顾虑真实存在 | SOD.md 痛点三（传图给第三方小作坊的隐私顾虑） | 创作在用户浏览器完成 = 硬差异点，对外话术要明示 |

## 3. 综合结论与下一步

### 3.1 创业验证结论

**PCV 18/24（Strong 下沿）+ 设计伙伴 2/5（验证缺口集中在付费意愿）→ Proceed with caution（谨慎推进）**

评分中 18 分的构成：当前方案痛感 10/12（价格、质量、便利三项严重）+ 我们的改进 8/12（质量与便利是硬改进，价格与效率是部分改进）。**没有一项是拍脑袋的 c**——价格维度对代做锚点的诚实处理，正是这份验证的价值所在。

### 3.2 市场调研结论

1. **量级**：贴纸楔子的 SOM 在千万级/年（3 年，中性 660 万），是生活方式生意不是百亿平台——但对 CEO「滴滴式」叙事的修正是：**SOD 的正确对标不是滴滴，是「印刷界的 Sticker Mule × (极小号) 滴滴供给网络」**——收入结构上更像 Sticker Mule（产品毛利驱动）而非滴滴（纯佣金驱动）。
2. **位置**：「高体验×低价」象限空位是结构性的，但认知教育成本自担——一句话认知「不用买机器也能做」必须贯穿所有对外物料。
3. **时机**：谷子店倒闭潮是警报也是机会——挤泡沫利好供给侧整合者，倒闭店主是现成的微产能候选池。

### 3.4 对既有战略文档的修正

1. **`PLATFORM.md` §1**：终局叙事中补充「收入结构对标 Sticker Mule（产品毛利驱动）而非滴滴（纯佣金驱动）」——滴滴类比保留于供给网络结构，商业模型类比换 Sticker Mule。防止团队用滴滴的补贴直觉做 SOD 的运营决策。
2. **`PLATFORM.md` §6 风险表**：补充「代做低价锚点压制定价能力」与「圈层挤泡沫期需求波动」两条市场侧风险（对策已列）。
3. **`SOD.md` §定价**：本调研不改变现行定价（9.9/7.9/5.9 三档），但 Van Westendorp 测试（P2 优先级）结果若 OPP 落在 8-12 元外，需回调档位。
