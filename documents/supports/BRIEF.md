## 1. 市场：聚焦国内

### 1.1 市场有多大

| 口径 | 数字 | 来源 |
|---|---|---|
| 谷子经济大盘（TAM 参照） | 1,689 亿元（2024，+40%）→ 2,000 亿（2025E）→ 3,000 亿+（2029E） | 艾媒咨询 |
| 泛二次元周边（参考口径） | 5,977 亿元（2024）；泛二次元用户 5.03 亿 | 艾媒咨询 |
| SAM：谷子经济中「自制/个性化」细分（贴纸+小卡+咕卡材料 ~3.5%，聚焦一二线 ~40%） | **~28 亿元/年**（手帐 48.7 亿 × 贴纸胶带 30% ≈ 14.6 亿交叉印证，同量级） | 调研 §2.1 |
| SOM（3 年） | **3,900 万 – 1.7 亿元/年**（自上而下与自下而上交叉验证，相差 1.5 倍内） | 调研 §2.1 |

**量级判断**：贴纸这个楔子的 SOM 是「千万级营收/年」的生活方式生意，不是百亿平台叙事。管道可平移小卡/立牌/贴膜，每个新品类是一轮新 SOM。**够支撑一门健康生意，且三收入线（订单+耗材+佣金）利润结构比纯佣金平台更厚。**

### 1.2 格局与玩家（四类）

| 类型 | 玩家 | 模式 | 关键事实 |
|---|---|---|---|
| 平台型定制 | **柔造**（A+ 轮，杭州）、**映糖**（自称 1000W+ 用户，深圳）、若映、米图师、桃桃定制等 7+ 家 | AI 前端 + 聚合订单 + 派单产业带工厂（无自有产能） | 一件起订已验证；吧唧 1.2-2 元、小卡 0.5-0.65 元/张；小程序主阵地 |
| 代做小作坊 | 淘宝/闲鱼店铺（海量） | 传图-沟通-等货 | 批量 5 元/200 张；分摊单张 0.5-2 元 |
| 自购硬件 | 极印 S1、汉印、米家、惠普 | 用户自购打印机 | S1 近 1,500 元；实测 819 元机器需印大几千张回本 |
| 替代方案 | 快印店/文印店 | 线下即取 | 标签逻辑，不懂圈层审美，不能自由排版 |

### 1.3 竞争者漏出来的破绽

| 破绽 | 证据 | 谁的破绽 |
|---|---|---|
| **慢是全场结构性痛点** | 所有平台「上传→中央工厂→快递 3-7 天」；NGA 用户提醒柔造「预留制作和发货时间」；小单排大单后面，聚合派单模式下无解 | 平台型全体 |
| **按批不按张** | 一件起订 ≠ 按张计价；无累进凑单结构 | 平台型全体 |
| **不能亲手调** | 工具全是「上传为主+模板辅助」，无深度创作；代做更是只传图等收货 | 平台型 + 代做 |
| **隐私顾虑** | 代做不敢传私人照片（手帐/庆生/亲子/宠物场景照片即隐私） | 代做小作坊 |
| **1,500 元门槛** | 年轻群体买不起也不常用，闲置浪费 | 自购硬件 |
| **价格战已打穿** | 吧唧 ¥0.99、小卡 ¥0.5——拼单价的路上已经挤满 7+ 家 | 平台型全体 |

### 1.4 从竞争看，机会在哪里

五平台共同指向一个空白：**没有人做「即时创作 + 就近履约」**；「高体验 × 低价」象限无人占据（结构性：代做的人力模式做不了亲手体验，硬件厂商的商业模式做不了低门槛）。我们带着不同入场券（S1 硬件资产）入场，不打价格战、不做「又一个柔造」。

**机会一句话**：全场都慢、都不能亲手调、都按批卖——「快 + 亲手 + 按张」的三角真空，还没有人占住。

## 2. 用户：双入口，不预设主次

### 2.1 用户是谁（双 ICP）

| | ICP-A 谷子/手帐圈层 | ICP-B 年轻父母（含毛孩子家长） |
|---|---|---|
| 年龄 | 15-25 岁学生/初入职场 | 25-35 岁 |
| 触发场景 | 无料制作、痛包痛桌、手帐装饰、吧唧自制 | 亲子成长记录、宠物贴纸（贴猫爬架/宠物用品/手机壳）、纪念品 |
| 频率 | 周级（高频创作者） | 月级（事件驱动） |
| 付费意愿 | 单次 20-70 元 | 单次 30-100 元，价格容忍更高 |
| 渠道 | 小红书/B站/超话/QQ群 | 母婴群/宝妈社群/朋友圈/商场线下 |
| 独特优势 | 密度与复购来源；圈层「订阅制」心智（手帐月消费 ~500 元） | 照片即隐私——隐私卖点最锐利的场景；竞争真空（柔造映糖全在谷圈饭圈厮杀，无人服务亲子/宠物线）；客单更高 |

**排序策略：双入口对照，Phase 0 数据定主次。**两线并行投放当 A/B 实验——谷圈线走小红书 KOC + 漫展摊位；亲子线走宝妈社群 + 商场快闪。Gate 0 出分渠道 CAC / 转化 / 客单 / 复购对比报告，Phase 1 据此定主攻方向。

### 2.2 使用场景（典型）

- **谷圈线**：给喜欢的角色做无料（漫展交换礼物）；痛包痛桌装饰；吧唧自制；手帐贴纸月度补充。
- **亲子线**：孩子照片做成贴纸贴冰箱/成长册/儿童房；宠物抠图贴猫爬架/宠物用品；全家旅行照做纪念贴纸；生日礼物。
- **共性**：内容是「我在乎的」（角色/孩子/毛孩子），图是现成的（有图人群），情感价值 > 功能价值。

### 2.3 目前满足了吗？痛点还剩什么

PCV 验证：现有方案痛点 10/12（价格、质量、便利三项严重问题）——需求被「半满足」，痛感明确：

| 痛点 | 现状 | 对我们的含义 |
|---|---|---|
| 价格 c | 自购 1,500 元门槛 + 耗材 2.75 元/张；819 元机器要印大几千张才回本 | 按张 9.9 元起 + 无硬件投入，落在「不心疼」区间 |
| 质量 c | 代做质量参差、无模切（到手自己剪）、**不敢传私人照片** | AI 抠图 + 模切成品 + 创作在自己设备完成 |
| 便利 c | 家印要维护喷头学软件；代做流程繁琐（传图-沟通-确认-等待） | 浏览器即用，一张起订，送货上门/自提 |
| 效率 b | 代做往返沟通慢（改一版等半天），发货 3-7 天 | 尝试同城当日达/次日达（见 §3.3） |

### 2.4 从用户看，机会在哪里

**机会一句话**：亲子/宠物线是竞争真空 + 隐私痛点最锐利的场景；谷圈线是密度与复购的来源——双线并行，用数据说话。

## 3. 定义与核心卖点

### 3.1 一句话定义

> SOD 是「在线创作—下单—当日到手」的贴纸 DIY 服务：上传自己的图，在浏览器里亲手设计，不用买机器、不用凑起订量，按张计价，成品就近履约当日达/到店自提——**把你在乎的东西，变成能贴出去的实体。**

认知传播压缩为一句：**「不用买机器，也能把喜欢的做成贴纸。」**（用户不知道这个选项存在——我们创造认知，不是回应搜索）

### 3.2 卖点 = 竞争破绽 × 用户痛点

| 卖点 | 对应竞争破绽（§1.3） | 对应用户痛点（§2.3） |
|---|---|---|
| **亲手**：浏览器里自己排版、实时预览，到手是「这是我做的」 | 工具全是上传型；代做零参与感 | 质量参差不可控；表达被中介截断 |
| **隐私**：创作在自己设备完成，抠图上云即删 | 代做必须把照片交给陌生人 | 亲子/宠物/私人照片不敢外传 |
| **按张**：一张起订、累进计价（第 5 张起 5.9） | 全场按批卖/凑起订 | 1500 元门槛被拆掉；便宜到日常挥霍 |
| **快**（尝试方向，见下） | 全场 3-7 天，慢是结构性痛点 | 即时满足的期待（中国次日达环境） |

### 3.3 关于「快」：我们的尝试清单（不是结论）

「快」是全场唯一无人占住的空位，但**我们还没证明自己能做到**——以下是需要尝试与验证的手段，每一条都有成本与不确定性：

1. **同城自营节点**：打印+模切设备在同城，截断「中央工厂+快递」链路——需实测单节点日产能上限与成本；
2. **自提点挂机**：谷子店/文具店/校园店寄放设备，用户动线上顺路取——需谈 2-3 家合作验证挂机话术（给店家带客流）；
3. **闪送补位**：承诺当日达的订单同城闪送配送——需测单量阈值下的阶梯价是否撑得住客单；
4. **漫展/快闪现场履约**：现场下单半小时自取——「快」的终极展示，也是地推获客（§5 战术）；
5. **承诺分层**：贴纸当日达 → 吧唧次日达 → 全品类逐级放开，**不提前透支承诺**。

验证标尺就是 Gate 0 的**当日达兑现率 ≥80%**（承诺当日达的订单中实际当日完成履约的占比）——做不到，就把「快」降级为次日达叙事，回供给布局层重审。**先做到，再说话。**

## 4. 终局与阶段

### 4.1 终局一句话

**消费端创作平台 + 分布式微产能履约网络**：SOD 品牌直连消费者做入口，购买商家套件的小商家与个人用户就近履约，收入 = 订单毛利 + 硬件 + 耗材 + 佣金三线叠加。滴滴是终局的结构类比（平台接单、节点履约），Sticker Mule 是收入结构的镜子（产品毛利驱动，非纯佣金）——均后置实施，Phase 0 只做自营。

### 4.2 三阶段

| 阶段 | 时间 | 目标一句话 | Gate（达标才进下一阶段） |
|---|---|---|---|
| **Phase 0 单城自营** | 12 周 | 跑通「创作→下单→履约」全链路，验证付费意愿与当日达可行性，双入口数据定主次 | Gate 0：周订单 ≥100 / 转化 ≥8% / 复购 ≥15% / UE 边际 ≥0 / SOP 文档化 / 当日达兑现率 ≥80% / 自提占比 ≥40% / 私域沉淀率 ≥25% / 双入口对照报告 |
| **Phase 1 供给扩张** | ~2027 H1 | 把 Phase 0 的 SOP 卖给首批外部商家（S1 重度用户 + 倒闭谷子店店主），B2B 单显性化承接 | Gate 1：外部商家 ≥5 家在网 / 订单质量达标率 ≥92% / 商家月增收 ≥1,500 元 / 套件回本 ≤6 个月 / 当日达占比 ≥60% |
| **Phase 2 平台飞轮** | 2027 H2+ | 自营转标杆店，城市复制，佣金+耗材成为主要毛利；市集在前置条件达标后开放 | Gate 2：单城佣金+耗材毛利覆盖该城全部运营成本 / ≥3 城复制成功 / 商家 NPS ≥40 |

```
2026 Q4          2027 Q1-Q2           2027 Q3+
────Phase 0──────┬────Phase 1──────────┬────Phase 2───────
单城 2C 自营试点   │ 供给扩张(5-10 商家)   │ 平台飞轮(多城)
12 周作战计划      │ 商家小程序+后台代码化  │ 佣金+城市复制+市集
双入口对照+Gate 0  │ B2B 单承接+kiosk 试点 │ (前置条件达标后)
```

## 5. Phase 0 详规（12 周作战计划）

### 5.1 战略目标（按验证优先级排序）

| 序 | 目标 | 为什么 | 量化出口 |
|---|---|---|---|
| ① | **付费意愿** | PCV 18/24 的最大缺口（设计伙伴验证 2/5，未验证项集中在愿意付费） | 创作→下单转化 ≥8% + UE 边际 ≥0 |
| ② | **当日达履约可行性** | 核心差异化主张的可行性——立不住则退化为「又一个柔造」 | 当日达兑现率 ≥80% + 自提占比 ≥40% |
| ③ | **双入口定主次** | 亲子/宠物线 vs 谷圈线，哪条是主攻——不拍脑袋，用分渠道数据定 | 双入口对照报告（CAC/转化/客单/复购） |

### 5.2 当期核心卖点（对外一句话）

**「不用买机器，也能把喜欢的做成贴纸——亲手设计，当天到手。」**

前提：前半句（认知）Phase 0 全程讲；后半句（当天到手）只在当日达兑现率数据站住后才放开讲——卖点兑现不了就是反向广告。

### 5.3 12 周战术

**W1-2 备战**
- 设备：S1 + 模切 + 耗材库存到位；自营节点设于办公场地一角（无需门店）
- 谈 2-3 家谷子店/文具店挂机自提点（寄放或分成）
- 飞书多维表格搭跑单系统：订单池→拼版状态→打印→发货/自提→对账
- Web App 上线（限单城），接通微信支付 + 快递100
- **跑单账本字段定版**：每单记耗材成本、人力分钟数、配送费、客诉/退货

**W3-6 双线冷启动**
- **谷圈线**：小红书/B站手帐·谷子圈 KOC 种草；首场漫展摊位（现场下单、半小时自取）；分渠道记录 CAC
- **亲子线**：宝妈社群/母婴群渗透；商场快闪位周末测试（亲子贴纸当场做当场拿）；分渠道记录 CAC
- 两线共用认知一句话「不用买机器，也能把喜欢的做成贴纸」；免运费券 + 首单免费打样降低尝试门槛
- 20 人圈层访谈并行（问问题不推销）：新增「你的图从哪来」「是否曾因隐私放弃代做」

**W7-10 提频与对照**
- 复购运营：30 日复购追踪、历史作品「再来一单」、凑单话术（「第 5 张只要 5.9」）实测
- 私域沉淀：企微/社群，把两线 KOC 流量沉淀为自有资产
- 当日达体验打磨：自提流程、闪送选项、时效承诺话术校准
- **双入口对照收数**：漫展 vs 商场快闪、谷圈 KOC vs 宝妈社群，分开记录自然流量转化率、客单价、复购

**W11-12 Gate 0 评审**
- 数据汇总、SOP 文档化收尾、评审会决策：进 Phase 1 / 迭代 / 退出

### 5.4 工作拆解（责任域）

| 域 | 事项 | 交付 |
|---|---|---|
| 产品 | Web App 上线（限单城）、支付/物流接通、数据埋点 | 可下单可支付的线上入口 |
| 履约 | 自营节点 SOP、拼版-打印-模切-包装流程、挂机自提点谈判 | 全链路 SOP 文档（Gate 0 项） |
| 获客 | 两线 KOC 投放、漫展/快闪执行、分渠道 CAC 记录 | 双入口对照报告（Gate 0 项） |
| 用户研究 | 20 人访谈（含「图从哪来」「隐私放弃」题） | 访谈纪要与 PCV 补充评分 |
| 数据 | 飞书跑单表格、UE 账本、Gate 0 指标看板 | 周报数据流 |

### 5.5 Gate 0 指标（九项，与 PLATFORM.md §8.1 一致）

**继承五项**：周订单 ≥100（需求真实）/ 创作→下单转化 ≥8%（体验成立，付费意愿代理）/ 30 日复购 ≥15%（黏性成立）/ 单均 UE 边际 ≥0（自营都不赚钱外包更不可能）/ 全链路 SOP 文档化（可复制给外部商家）。

**2C 四项**：当日达兑现率 ≥80% / 自提占比 ≥40%（若用户全要快递，「快」的成本结构不成立）/ 私域沉淀率 ≥25% / **双入口对照报告完成**（亲子线 vs 谷圈线的分渠道 CAC、转化、客单、复购对比——Phase 1 主攻方向的决策输入）。

### 5.6 数据采集与分析计划

| 数据 | 采集方式 | 分析节奏 |
|---|---|---|
| 订单与 UE | 飞书跑单表格（每单：渠道来源、耗材成本、人力分钟、配送费、客诉） | 周复盘：单均 UE、分渠道客单 |
| 获客 | 每张券/每个 KOC 链接/每场线下活动独立标记 | 周复盘：分渠道 CAC；W11-12 汇总双入口对比 |
| 转化漏斗 | Web App 埋点（访问→上传→编辑→下单） | 周复盘：漏斗卡点定位 |
| 履约时效 | 订单表格时间戳（下单→拼版→打印→送达/自提） | 周复盘：当日达兑现率、自提占比 |
| 复购与私域 | 30 日复购标记、企微入群标记 | W7 起双周追踪 |

## 6. UE 单均经济框架

> 框架先行，**具体数字待 Phase 0 实测校准**（人工项按半人工估算，是最不确定、规模化后降幅最大的一项）。

### 6.1 单均成本结构（按现有估算）

| 类型 | 项 | 元 |
|---|---|---|
| 固定/单 | 运费（通达系对公 1kg 内；自提则为 0） | 5.0 |
| 固定/单 | 打包人工 + 包装材料 | 1.8 |
| 变动/张 | 耗材（99 元 / 36 张） | 2.75 |
| 变动/张 | 打印切割人工 + 损耗 | 0.8 |

**总成本 = 6.8 + 3.55 × 张数**（快递口径；自提口径 = 1.8 + 3.55 × 张数 + 闪送选项实测定）

### 6.2 收入与毛利（累进计价，`SOD.md` 定价章）

第 1-2 张 9.9 元 / 第 3-4 张 7.9 元 / 第 5 张起 5.9 元；N=1 收运费 5 元，N≥2 包邮。

| 总张数 N | 用户实付 | 我方成本 | 毛利 |
|---|---|---|---|
| 1 | 14.9 | 10.35 | 4.55 |
| 2 | 19.8 | 13.90 | 5.90 |
| 5 | 41.5 | 24.55 | 16.95 |
| 10 | 71.0 | 42.30 | 28.70 |

毛利随 N 严格单调递增（每张边际价均高于 3.55 元变动成本）；第 5 张起边际毛利率固定 39.8%，整体毛利率收敛在 ~40%——对实体商品健康。

### 6.3 敏感变量（Phase 0 重点实测）

| 变量 | 影响方向 | 备注 |
|---|---|---|
| **自提占比** | 自提省 5 元运费/单，是单均 UE 最大杠杆 | 这就是自提占比 ≥40% 进 Gate 0 的原因 |
| **履约人力效率** | 人工 0.8 元/张是半人工估算，流程熟练+并单打印后降幅最大 | 跑单账本记「人力分钟数」正是为此 |
| **复购** | 第二单毛利 5.90 元 > CAC 期望 1.60 元，回本只需 ≥36% 用户下第二单 | 复购 ≥15% 是底线，36% 是回本线 |
| **获客成本** | 注册券+邀请机制 CAC 期望 ~1.60 元/人（`SOD.md` 测算锚），双入口实测可能上浮 | 分渠道记录，不买量 |

## 7. 「为什么不」负面清单（内部质疑预答复）

| 质疑 | 立场 | 一句话理由 |
|---|---|---|
| 「跟代打价格战吧，5 元 200 张都有了」 | **不打** | 价格锚已被若映（吧唧 ¥0.99）打穿，拼单价毫无胜算；打「亲手+隐私+模切+快」组合拳，免费打样抵消首次尝试摩擦 |
| 「为什么不先做小程序？竞品都是小程序」 | **Web 先行** | 探索期定义未稳，Web 迭代最快（GitHub 部署浏览器即看）；竞品全选小程序恰说明要 A/B 验证入口损耗，编辑器核心与 UI 解耦保证后切 App 可复用 |
| 「买套现成电商后台不就完了」 | **不买** | 市面不存在「按需贴纸生产调度」垂直方案（电商 SaaS 是店铺逻辑、外卖 SaaS 是餐饮逻辑）；拼版与派单是差异化本体，**能买到的都不是壁垒**；Phase 0 用飞书表格跑单学需求 |
| 「加上 AI 生图更有卖点」 | **MVP 不做** | 每次调用是实打实的接口成本，且分散编辑器打磨注意力；核心双 ICP 均为「有图」人群（柄图/孩子照片/宠物照片都是现成的），AI 生图是 Phase 1+ 期权 |
| 「学滴滴补贴抢用户」 | **不补贴** | 补贴买不来复购只买来羊毛党；单均经济必须自己站得住（Gate 0 UE 边际 ≥0），免费打样/免运费券已够降低首次尝试门槛 |
| 「直接上商场常驻 kiosk 投放」 | **Phase 0 不上** | 月租数千-数万+进场费+人员维护，万元级有界投入约束下不是起点；先用漫展摊位（数千元/场）和商场快闪位（数百-数千元/日）做对照实验，数据说话后再决定 Phase 1 押不押 |

---

> **一句话总结**：全场都慢、都不能亲手调、都按批卖——我们用「快（待验证）、亲手、按张」占住这个真空；亲子/宠物线与谷圈线双入口并行，Phase 0 十二周拿数据定主次；UE 框架已立、数字待实测；每一步都有 Gate 门槛纪律——先做到，再说话。
