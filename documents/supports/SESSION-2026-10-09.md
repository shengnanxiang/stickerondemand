## 四、需求刺激与节点 ROI（对第 5 点的回答）

### 4.1 三个前提纠正

- **弹性 ≠ 小**。泡泡玛特、Jellycat、整个谷子经济全是弹性需求，照样百亿市场。弹性需求不由产品功能触发，由**情绪和社交场景**触发——刺激需求不是「让用户意识到需要贴纸」（永远不会），而是**把下单入口放进情绪已经发生的地方**。
- **需求已存在，只是形态不同**。谷圈用户现在就在买贴纸（量产、别人图样、等 3-7 天快递）。我们不是创造需求，是**转化既有支出**：「同样的钱，从买别人做的换成做自己的」——不需要教育市场，只需要被看见。
- **瑞幸类比要拆开用**：交互模型（小程序下单 + 就近取货）可搬；**选址逻辑搬不得**——咖啡是地理规律性需求（固定时段、固定地点，所以瑞幸在写字楼底商加密），贴纸是情绪触发型需求，节点要跟着「情绪发生的地方」走（漫展 / 谷子店 / 小红书信息流），不是跟着人流走。

### 4.2 三个刺激机制

| 机制 | 逻辑 | 证据 |
|---|---|---|
| **过程即广告** | 制作过程有观赏性，停得住路人；每张贴纸是移动广告（贴上手机/水杯出街即曝光） | 劳伦斯客户买机器引流——为观赏性付费的市场证据 |
| **冲动闭环（快 = 需求闸门）** | 冲动的「想要」窗口只有几分钟~几小时，衰减极快；柔造架构只能接计划性需求，**结构上接不住冲动需求**——做快不是为了比竞品快一点，是打开一个他们碰不到的需求池。ROI 叙事核心：快是收入开关，不是成本 | `POD平台对标分析` §4.3 成本模型 |
| **双需求波形互补** | 谷圈买**产出**（冲动型，吃峰值转化）+ 亲子买**过程**（计划型、客单更高，本质 = 陶艺/银饰 DIY 工坊生意，可做**预约时段**——产能预先卖掉）——同一台机器峰谷双吃，利用率 > 单一需求 | 双 ICP（`PLATFORM.md` §6） |

### 4.3 自营节点 ROI 四层防御

1. **形态选便宜的**：漫展按场次投（人流是买来的）/ 谷子店挂机（寄放分成，近零租金）/ 常驻 kiosk 有数据才上——会被挑战 ROI 的是「常驻」形态，Phase 0 别碰；万元级有界 + 设备残值（§8.1 纪律）。
2. **收入叠加**：C 端散单 + B2B（机构周边/展会无料/谷子店供货）+ 事件单——利用率是生死指标，不该只算 C 端一条流水线。
3. **记账方式**：节点同时是自提点 + 体验场 + 广告位，成本应部分计入**获客**而非履约——劳伦斯客户「买机器引流」恰恰证明此账成立。
4. **让数据辩护**：Gate 0 指标（复购 ≥15%、自提占比 ≥40%、分渠道 CAC）——第一笔投入小到不需要向任何人辩护，数据出来后 ROI 从「信仰之争」变「算术题」。

### 4.4 遗留真风险

「悦己一次性」需求天花板：上述机制都提高需求被触发的**概率**，但没有一个保证**复购**——Gate 0 把复购率 ≥15% 前置拦截正是为此。刺激手法可以全上（都不贵），节点重投入等复购数据说话。

## 五、等待悖论：看到→等待→流失 vs 没看到→没需求

**矛盾表述**：①用户看到，可能带出需求，但需制作等待，会不会流失？②用户没看到，没带出需求，这时快也无从谈起。

### 5.1 拆解框架：这是两条漏斗被叠进同一框架

**关于 ①：杀转化的不是等待，是无边界、无意义的等待。**

- 事实锚点：等 30 分钟奶茶的人没有流失（喜茶排过两小时）。
- 三层拆解：
  - **亲子/情侣：等待就是产品**——买的是「一起做 30 分钟」的过程，等待 = 体验本身（陶艺/银饰 DIY 工坊同理）；
  - **冲动型（谷圈）：等待要被吸收**——取件码 + 先去逛（「半小时后自取」茶颜悦色模式）；等待自带内容：机器现场打印切割的「生产戏剧」是挽留装置；排队本身是社会证明（奶茶店逻辑）；
  - **复购用户：等待为零**——瑞幸模式，到店前小程序已下单，到店即取。等待问题只存在于首单自然客流，不是模型固有成本。
- 已有实现：demo 里 Q01 排队号 + 4 位取件码 + 预计等待——等待被可视化、被承诺，即为「有边界」。

**关于 ②：把「看到」等同于「物理看到」是假设错位——内容就是中介化的看到。**

- 小红书视频里机器打印切割那 15 秒，和站在机器前看，触发的是同一条神经通路。双线冷启动里 KOC 内容的任务就是**把线下引流的戏剧性打包成内容二次分发**。
- **速度要求是渠道相对的**：

| 渠道 | 冲动衰减窗口 | 需要的速度 |
|---|---|---|
| 线下现场 | 分钟级 | 30 分钟现场取 |
| 线上内容触发 | 小时~1 天 | 当日达 |
| 计划型（亲子预约） | 天级 | 预约时段，体验优先 |

- 关键结论：柔造们的结构极限（3-7 天）**连线上这个宽松窗口也进不去**——快在线上同样成立，不是要 3 分钟送达，是要「情绪还热着时送到」，而竞品结构上做不到。

**第三态（原矛盾漏掉的）：看到但没买 = 种草 + 位置记忆。**

「哦，这种东西这里能做」——线下节点同时是线上服务的实体广告位；贴纸本身是移动广告。两渠道互为漏斗：线下看到 → 记住 → 线上刷到内容 → 下单 → 到店自提 → 又看到机器（闭环）。

### 5.2 诚实说真正难的点

不是等待，是**峰值排队**与**谷值闲置**：

- 峰值：一台机器 8-14 秒/张（demo 实测），10 张约 2 分钟，半小时承诺下单机理论吞吐 ~150 张/时——漫展峰值可能击穿，靠预约时段吸收计划需求 + 排队号管理预期；
- 谷值：**「周二下午没人路过」才是节点真正的敌人**——等待流失是表层焦虑，「没有需求可等」才是要花力气的地方。解法回到 §4.2 双需求波形互补 + §4.3 B2B 填谷：让机器别闲着，而不是让人别等。
