# Sticker On Demand

# 本质

> **十年后，什么依然成立？**

## 什么在变（不押注）

| **变量** | **具体形态** |
| --- | --- |
| 技术 | AI 抠图、AI 生图、热升华打印与覆膜、模切工艺 —— 约若干年一次代际升级。 |
| 载体 | 相纸贴纸。未来可能是贴膜、可打印织物或其他物理介质。 |
| 玩法与风格 | 手帐 → 谷子 → 痛包 → 痛桌，十年一换。 |
| IP 热点 | 今年是这批角色，明年是那批。 |
| 渠道 | 线下一体机 → 淘宝 / 闲鱼代做 → Web App / 小程序。 |
| 人群标签 | 手帐党、谷子党、学生、年轻父母、毛孩子父母 —— 标签随风向漂移。 |

这些是手段层，不是本质层。它们会过时，押注它们等于押注保质期。

## 一句话本质

:::
**以极低的成本，把「我在乎的东西」变成「看得见、摸得着、能贴出去的实体」。**
:::

### 三个不变要素与它们导出的硬约束

| **要素** | **含义** | **MVP阶段排除 / 约束什么** |
| --- | --- | --- |
| **我在乎的** | 内容来源必须是「我」，不是商家 | *   不依赖独家 IP<br>    <br>*   不做官方内容授权<br>    <br>*   不做模板商城与作品社区 |
| **物化（可触摸）** | 离开屏幕，进入物理世界 | *   纯线上形态（壁纸、滤镜、头像框）不是战场<br>    <br>*   **实体交付是本体**，线上只是下单前的手段 |
| **低成本 + 随手可做** | 表达必须便宜到可以日常挥霍 | *   必须无硬件投入、无起订量、单张低价、编辑器门槛极低 |

### 稀缺位置的位移

同一个诉求，被挡住的原因随时代移动了：

|  | 过去（示例：童年买卡通黏纸） | 当下 |
| --- | --- | --- |
| 想要的 | 拥有喜欢的卡通形象 | 拥有**我指定的**那个形象 / 照片 / 瞬间 |
| 被什么挡住 | **购买力**（钱不够） | **供给缺口**（官方只印它想印的；代做不敢传图、懒得排版） |
| 稀缺的位置 | 买不起 | 买不到 |

稀缺的位置从「购买力」移到了「供给」，但**「我喜欢的东西，能不能变成我摸得到的实物」这个诉求一分没动**。

## 两条长线判断

1.  **管道即资产**：十年后技术更强、渠道更碎、IP 更替、玩法翻新，但「人要把自己在意的东西变成实物体，且便宜到随手就做」不变。SOD 长线积累的是**「任意内容 → 低成本实体贴纸」这条管道本身**（上传 / 生成 → 抠图排版 → 一张起印 → 送货上门），不是某个玩法或某个 IP。
    
2.  **基础设施型，不是内容型**：「喜欢」的来源攥在用户与 IP 方手里，我们不掌握内容，就不可能靠内容独占。护城河只有两条——**管道效率**（更便宜、更快、更简单）与**数据复利**（作品库、创作习惯、审美偏好）。资源投向由此决定。
    

# 定位

## 一句话定义

SOD 是「在线创作—下单—送货上门」的贴纸 DIY 服务：用户上传自己的图，在浏览器里亲手设计，不用买机器、不用凑起订量，成品贴纸直接送到手上——**把你在乎的东西，变成能贴出去的实体**。

## 愿景

让「把自己的东西变成贴纸」成为年轻人表达自我的日常方式——想做就做，做了就贴，贴了就晒。

## 核心价值

极印 AI 贴纸照片打印一体机 S1 已经证明了需求是真实的：借助 AI 抠图、AI 生图与海量模板，配合热升华打印与覆膜工艺，用户能轻松做出**撕下可贴、防水耐久**的个性化贴纸——而且是按轮廓切好的成品。

但一台机器售价近 1500 元，后续耗材还要 36 张 99 元。对它面向的年轻群体来说，这笔硬件投入门槛过高。

SOD（Sticker on Demand）要消除的，正是这 1500 元的硬件门槛：用户在浏览器里亲手创作、实时预览，下单后成品贴纸送货上门。**不买机器，也能得到机器做出来的贴纸** —— 按张计价、无起订，想做几张做几张。

相比闲鱼 / 淘宝的「传图代做」，SOD 的差异在于**亲手创作**：用户在自己的浏览器里一步步调整、实时预览，成品因此带上「这是我做的」的归属感。

> **「亲手创作」是当期差异化手段，不是本质**。它解决的是「官方制品碰不得、代做敢传图也不好看」这个具体处境；一旦出现更省力的创作方式（例如一句话生成），被替代的首先就是这个手段，依附其上的价值也随之失效。不变的那一层始终是：以极低的成本把「我在乎的东西」变成看得见、摸得着、能贴出去的实体。

需要明确的是，SOD 不与官方授权制品竞争。二次元用户普遍认为门店买到的官方卡片是「正版」，自己在家 DIY 的是「盗版」——但这恰恰说明两者满足的是两种不同需求：门店买的是「拥有官方制品」，SOD 卖的是「我自己做了什么」。用户从没指望 SOD 提供正版，他要的是把自己的图变成贴纸。因此产品定位与对外表述一律不碰「正版」二字，价值主张落在**「这是我的」**——内容来自用户自己、独一无二；而「亲手创作」是当前把这一点做实的手段。

# 市场与用户洞察

## 核心目标人群

### 特征

> **本质人群**：有想物化的东西、且现有供给够不到的人。下列为当期入口人群——他们的「在乎」最强烈、供给缺口最明显、转化最快，因此作为起步聚焦。

*   **年龄与人生阶段**：主要覆盖两部分人群
    
    *   一是 15–25 岁左右的学生（高中生、大学生）与初入职场新人；
        
    *   二是年轻父母，含养宠物的「毛孩子父母」。
        
*   **性别**：中性。男女都会用 DIY 贴纸表达各自喜好，无明显性别偏向。
    
*   **城市层级**：一线市场最优，二线次之；初期不覆盖下沉市场。
    
*   **当期入口人群**：
    
    *   起步阶段核心是手帐 / 潮玩 / 谷子（周边收藏）爱好者；
        
    *   学生、职场新人、年轻父母、宠物党等为更广的目标群体。
        
*   **消费心智**：起步阶段用户主要为「悦己」与「社交分享」买单，情绪与表达价值优先，价格上要便宜到不心疼、可以日常挥霍。
    

### 场景

> 说明：以下按人群分类列举，均为示例而非穷举，后续可持续补充。整体贯穿「悦己」与「做了之后晒出来」的分享心智。

1.  **手帐 / 潮玩 / 谷子党**（谷子 = IP 周边商品，音译自 goods；起步核心人群）
    
    1.  **手帐与日记装饰**：把照片、贴图抠出来排版，做成装饰手帐本、日记的贴纸。
        
    2.  **痛包与谷子展示**：自制角色 / 偶像小卡、吧唧（徽章，音译自 badge），用于痛包（外侧带透明夹层、用来密集展示周边的包）的夹层，以及痛桌、痛收纳等「痛系」物件（把喜欢的周边密集铺满日常物件的玩法）。
        
    3.  **潮玩衍生**：自制立牌、展示板贴纸，作为亚克力摆件的平价替代。
        
2.  **学生与职场新人**
    
    1.  **校园社团 / 班级 / 毕业季物料**：活动贴纸、班徽、毕业纪念。
        
    2.  **情侣与闺蜜纪念贴**：合照做成贴纸互赠，贴手机壳、水杯。
        
    3.  **旅行与打卡纪念**：旅行照做成贴纸，贴行李箱、旅行手帐。
        
3.  **年轻父母（含毛孩子父母）**
    
    1.  **亲子成长记录**：孩子成长、家庭日常做成贴纸，贴冰箱、成长册、儿童房。
        
    2.  **宠物主题贴纸**：宠物抠图做成贴纸，贴宠物用品、猫爬架、手机壳。
        
4.  **聚会与物件点缀**
    
    1.  **聚会活动**：譬如有家人或朋友过生日，在预定蛋糕的同时制作庆生的贴纸（可延伸至婚礼、节日、伴手礼）。
        
    2.  **物件点缀**：年轻人定制贴纸，贴在单车上、头盔上、包包上、滑板上，彰显个性（可延伸至手机壳、水杯、行李箱、笔记本）。
        

### 痛点

*   **硬件与门槛高**：一体机近 1500 元 + 耗材投入，年轻群体购买门槛过高，没法随时为自己的创意买单。
    
*   **DIY 参与感弱**：闲鱼 / 淘宝小作坊价格低、起订灵活，但属于「代做」——用户只传图等收货，缺亲手创作、实时调整的参与乐趣。这是 SOD 当期相对低价方案的主要差异点（见「本质」一节：亲手创作是当期手段，非本质）。
    
*   **隐私顾虑**：手帐、庆生、宠物等贴纸常含个人照片，传给第三方小作坊 / 淘宝店代做，存在照片外流、被留存的明显顾虑。
    

### 需求

1.  **零硬件门槛的在线创作**：在 Web 端（浏览器）里就能亲手做，免去 1500 元机器与耗材投入。MVP 阶段只做一个 Web App，不做小程序 / 多端。
    
2.  **能亲手做出成品的编辑器**：AI 抠图、素材与起点模板、实时预览，让用户从上传到成稿一步步看得见结果。
    
3.  **单张低价、无起订**：**一张（7 寸相纸）即可下单**，一张纸上想排几个贴纸图案就排几个——没有传统印刷动辄数百张的起订量，像买张纸一样轻松。
    

# MVP 功能定义

> 第一步只做一个 **Web App（浏览器端）**，不做小程序 / App / 多端。

## 账号与登录

*   支持**微信**注册 / 登录
    
*   支持**手机号 + 短信验证码**注册 / 登录
    

## 地址管理

*   收货地址的增、删、改、查
    
*   支持设置默认地址
    

## DIY 编辑器（Web 端，产品本体）

*   **上传图片**：支持 JPEG、PNG（建议补充 HEIC——iPhone 照片默认格式，不支持会卡住大量用户）
    
*   **图像处理**：排版、预览等渲染在浏览器端完成；**AI 抠图调用云端服务**（原图需上传，隐私按下方底线执行）
    
*   **AI 抠图**：调用云端服务自动去背
    
*   **抠图修补**：橡皮 / 恢复笔刷，手动修正抠图边缘
    
*   **画布与排版**：缩放、旋转、移动、层级调整；一张相纸的画面内可排布若干个贴纸图案
    
*   **文字**：添加文字，支持字体、字号、颜色
    
*   **素材与起点模板**：边框、形状、字体、通用装饰元素 + 少量布局框架，**嵌在编辑器内**作为「从这里开始」的起点；不建独立模板商城。素材须为**通用、无 IP** 内容（核心人群大量涉及 IP 二次创作，官方提供 IP 素材有侵权风险）
    
*   **实时预览**：所见即所得，可看到最终成品效果（含模切轮廓 / 白边）
    

> **MVP 不做 AI 生图**：文生图每次调用都是实打实的接口成本，且会分散对编辑器本身的打磨。MVP 只做「上传照片 → AI 抠图 → 修补 → 排版」，创作起点交给素材与布局框架承担。留到创作需求被验证后再评估。

> **待细化**：相纸规格（一张 = 一张 7 寸相纸）、一张纸上可容纳的贴纸数量上限、异形切割的边距与安全区要求——**复用极印 AI 贴纸照片打印一体机 S1 已有能力**，待 S1 详细 PRD 提供后补全。

## 作品与草稿

*   保存未完成的作品草稿
    
*   历史作品列表，支持从历史作品「再来一单」复用
    

## 下单与结算

*   **计价单位：按「张」计价，一张起订**——一张 = 一张 7 寸相纸，上面可自由排布若干个贴纸图案
    
*   **结算袋**：一次结算可聚合多个不同作品，每个作品可单独设份数（同一设计做几份用于送人）；**按本次结算的总张数计价**
    
    *   这不是传统商品购物车——里面装的是用户自己的作品，不是待售商品
        
*   **运费与优惠**：见「定价与成本结构」
    
*   选择收货地址
    

## 支付

*   微信支付、支付宝**扫码支付**
    

## 我的订单

*   订单列表与订单详情
    
*   订单状态流转：待支付 → 制作中 → 已发货 → 已完成（含超时未支付自动关单）
    
*   物流信息查看
    

## 后台生产履约（用户不可见，MVP 可半人工）

*   订单导出为可打印文件（一张相纸一个文件，版式复用 S1 已有拼版规则）
    
*   发货后回填物流单号
    

## 明确不做（MVP 范围之外）

*   小程序 / App / 多端
    
*   独立模板商城、UGC 模板市场、作品社区
    
*   分享 / 晒单
    

# 定价与成本结构

## 成本模型

| 类型 | 项 | 元 |
| --- | --- | --- |
| 固定 / 单 | 运费（通达系对公，1kg 内） | 5.0 |
| 固定 / 单 | 打包人工 + 包装材料 | 1.8 |
| 变动 / 张 | 耗材（99 元 / 36 张） | 2.75 |
| 变动 / 张 | 打印切割人工 + 损耗 | 0.8 |

**总成本 = 6.8 + 3.55 × 张数**

> 人工项按 MVP 半人工估算，是最不确定、规模化后降幅最大的一项；运费取通达系对公 1kg 内均价，江浙沪可更低。

## 计价规则

*   **计价单位**：一张 = 一张 7 寸相纸
    
*   **阶梯按「一次结算的总张数」计**，不绑定同一设计的重复份数——用户可以做几个不同设计一起下单
    
*   **累进计价**：第 N 张的价格只作用于这一张，**不给前面已计价的张数退差价**
    
*   **运费**：N = 1 收运费 5 元；N ≥ 2 包邮
    

### 档位

| 第几张 | 单价 |
| --- | --- |
| 第 1–2 张 | 9.9 |
| 第 3–4 张 | 7.9 |
| 第 5 张起 | 5.9 |

三档、每档降 2 元，断层整齐好记。

> **底价为什么放在第 5 张而不是第 10 张**：用户够不到的折扣等于没有折扣。第 10 张要凑到 71 元以上才吃得到 5.9，初期用户几乎不会走到，这个档位实际只存在于价目表上，不参与任何人的下单决策；第 5 张（41.5 元）是「多做几个设计一起下单」就能自然达到的量级。把底价挪到伸手可及的位置，折扣才真正开始起作用。

### 总价与毛利

| 总张数 N | 第 N 张单价 | 用户实付 | 均价 | 我方成本 | 毛利 |
| --- | --- | --- | --- | --- | --- |
| 1 | **9.9**（＋运费 5） | 14.9 | 14.90 | 10.35 | 4.55 |
| 2 | 9.9 | 19.8 | 9.90 | 13.90 | 5.90 |
| 3 | **7.9** | 27.7 | 9.23 | 17.45 | 10.25 |
| 4 | 7.9 | 35.6 | 8.90 | 21.00 | 14.60 |
| 5 | **5.9** | 41.5 | 8.30 | 24.55 | 16.95 |
| 6 | 5.9 | 47.4 | 7.90 | 28.10 | 19.30 |
| 7 | 5.9 | 53.3 | 7.61 | 31.65 | 21.65 |
| 8 | 5.9 | 59.2 | 7.40 | 35.20 | 24.00 |
| 9 | 5.9 | 65.1 | 7.23 | 38.75 | 27.35 |
| 10 | 5.9 | 71.0 | 7.10 | 42.30 | 28.70 |
| 12 | 5.9 | 82.8 | 6.90 | 49.40 | 33.40 |

毛利 = 实付 −（6.8 + 3.55 × N），**随 N 严格单调递增**（每加一张的毛利增量：N = 2 为 +1.35，第 3–4 张为 +4.35，第 5 张起为 +2.35）。

> **「第 5 张 5.9」是边际价，不是均价**：5 张总价 41.5 元、均价 8.30 元。对外话术用「第 5 张只要 5 块 9」，不要用「5 张平均 5.9」。

> **N ≤ 4 的价格一分未动**（14.9 / 19.8 / 27.7 / 35.6），因此优惠券面额上限、CAC、回本测算全部不受本次调整影响——这也是可以把底价提前的底气所在。

> **代价**：第 5–9 张各由 7.9 降到 5.9，即 N = 5 每单毛利少 2 元、N = 6 少 4 元……N ≥ 9 起每单少 10 元封顶。同时**大单毛利率不再随 N 上升**：第 5 张之后每张的边际毛利率固定为 2.35 / 5.9 = 39.8%，整体毛利率从 N = 5 的 40.8% 缓慢收敛到 40% 附近（原第 10 张方案可达 47.8%）。毛利**额**仍在增长，增长的是规模而非利润率——40% 毛利率对实体商品仍然健康。

### 为什么用累进而非「整单按一个价」

若采用全单重定价（达到某档后整单所有张按新价重算），新档起点 b、单价由 P 降到 P' 时须满足：

*   总价不塌陷：`b ≤ P / (P − P')`
    
*   我方毛利不塌陷：`b < (P − 3.55) / (P − P')`
    

即**单价每降 1 元，档位起点最多只能往后挪 1 张**——因为降价要给前面所有张退差价。据此，5.9 档在全单重定价下的起点最晚只能是第 2 张（`b ≤ (7.9 − 3.55) / (7.9 − 5.9) = 2.17`），第 5 张绝无可能。

把同样的档位结构（1–2 张 9.9、3–4 张 7.9、第 5 张起 5.9）换成全单重定价实测：买 4 张 31.6 元、买 5 张 29.5 元——**多买一张反而便宜 2.1 元**，我方毛利从 10.60 塌到 4.95。

累进计价没有这个问题：每张的边际价都高于 3.55 元变动成本，毛利天然单调递增，且保住了「第 5 张起 5.9」这个有冲击力的钩子。

> **另**：不用「满 N 张包邮」硬门槛。跨过门槛时我们放弃 5 元运费收入，若要毛利不降，新增那张的售价须 ≥ 9.2 元——等于没有折扣空间。改为 N = 1 收运费、N ≥ 2 包邮，运费落差发生在金额最小、毛利最可控的第一档。

## 优惠券与获客成本

### 发放规则

两种券面额都是 5 元，但性质不同：

| 券 | 获取 | 适用范围 | 用后实付 |
| --- | --- | --- | --- |
| **免运费券** | 新注册即得 1 张 | **仅 N = 1 订单**（免 5 元运费） | 9.9 元 |
| **5 元通用券** | 邀请 **3 位新用户完成注册**得 1 张，可累计 | **任意订单**，单笔限用 1 张 | 原价 − 5 元 |

*   券绑定账号、有效期 30 天
    
*   邀请奖励每账号累计上限 5 张
    
*   被邀请人须为从未注册过的新用户（手机号 / 微信 openid 判重）
    

> **为什么邀请奖励用通用券而不是免运费券**：免运费券只对「只做 1 张」的用户有价值，对习惯做 2–3 张的活跃老用户价值为 0——作为邀请奖励，它对我们要激励的那批人激励失效，而能用上的恰恰是我们不想鼓励的单张下单。通用券对所有人都有 5 元价值，且不释放「欢迎单张」的信号。

### 单张券的成本

| 券 | 用在哪 | 该单毛利 | 反事实 | 净投入 |
| --- | --- | --- | --- | --- |
| 免运费券 | N = 1 | −0.45 | 无券则不下单 | **0.45** |
| 5 元通用券 | N = 1 | −0.45 | 无券则不下单 | 0.45 |
| 5 元通用券 | N = 2 | +0.90 | 他本来就会下 N = 2（毛利 5.90） | **5.00** |
| 5 元通用券 | N = 3 | +5.25 | 同上 | 5.00 |

免运费券是**转化工具**（把不下单变成下单）；通用券用在已包邮的订单上是**纯让利**，按 5.00 元计成本。

### 通用券面额上限

硬约束是最小多张订单的毛利：N = 2 毛利 5.90 元。券面额超过它，用户下 2 张单我方就纯亏。

**面额 ≤ 5.90 → 取 5 元**（留 0.90 元毛利缓冲）

| 面额 F | N = 2 用券后毛利 | 套利收益（刷 3 个号） |
| --- | --- | --- |
| 3 | 2.90 | 4.35 |
| **5** | **0.90** | **6.35** |
| 5.9 | 0.00 | 7.25 |
| 6.9 | −1.00 | 8.25 |

面额 10 元以上刷号即有利可图（3 个接码手机号成本约 3–9 元），5 元同时是毛利上限和套利安全线。

### 邀请档位最优化

每邀请成功 X 人发 1 张 5 元通用券：新增 X 个用户，多发出 X 张注册券（0.45 × X）+ 1 张通用券（5.00）。

**CAC = 0.45 + 5 / X**（100% 核销的成本上限口径）

| 邀请人数 X | CAC（元 / 人） | 通用券摊薄到每人 | 评价 |
| --- | --- | --- | --- |
| 1 | 5.45 | 5.00 | 退化成「互邀即得」，刷号成本极低 |
| 2 | 2.95 | 2.50 | 偏松 |
| **3** | **2.12** | **1.67** | **推荐** |
| 4 | 1.70 | 1.25 | 备选 |
| 5 | 1.45 | 1.00 | 门槛明显抬高，达成率下滑 |

**取 X = 3 的理由**

1.  **成本集中在通用券，摊薄收益最大的区段是 1 → 3**：X 从 1 到 3 把 5 元摊薄到 1.67 元/人，是降幅最陡的一段；X 从 3 到 5 只再省 0.67 元，4 → 5 仅省 0.25 元。
    
2.  **达成率的损失大于省下的钱**：邀请 3 人是「朋友圈转发 + 私聊几个」能做到的量级，邀请 5 人已需要运营技巧，达成率明显下滑。裂变要的是规模，把门槛抬到没人够得着，省下的钱毫无意义。
    
3.  **X = 1 不设防**：两人互邀即各得 1 张，等于无限发券。X = 3 使刷号成本翻 3 倍。
    

> **留一个可调杠杆**：奖励券从免运费券（0.45）换成 5 元通用券后，奖励成本占比大幅上升，提高 X 的省钱效果比之前明显得多（3 → 5 可省 0.67 元/人，此前仅 0.06）。若日后裂变数据证明用户能稳定邀请 5 人，可把 X 提到 5、CAC 降到 1.45。

### 更新后的获客成本

| 方案 | CAC（100% 核销上限） | CAC（期望值） |
| --- | --- | --- |
| 仅注册送免运费券 | 0.45 元 / 人 | ≈ 0.27 元 / 人 |
| **注册送券 + 邀请 3 人送 5 元通用券** | **2.12 元 / 人** | **≈ 1.60 元 / 人** |

期望值按注册券核销率 60%、通用券核销率 80% 估（主动要券的人更可能用掉）。

> **注意方向**：邀请机制让 CAC 从 0.45 **上升**到 2.12，不是下降。多花的钱买的是**裂变规模**而非更低的单价——不做邀请，这部分用户根本不会来。

### 回本测算

*   第二单毛利（N = 2，包邮）为 5.90 元，是 2.12 元 CAC 的 2.8 倍——**单个用户只要下第二单即回本**
    
*   **整体回本需 ≥ 36% 的获客用户产生第二单**（2.12 / 5.90）
    
*   若用户只薅首单就走，我方在该用户身上净亏 2.12 元——因此券的真实成本取决于留存，而非券本身
    

### 防滥用

*   被邀请人须为全新用户（手机号 / 微信 openid 判重）
    
*   同一账号通过邀请累计最多得 5 张
    
*   **单笔订单限用 1 张通用券**——否则 5 张叠加减 25 元会击穿毛利（N = 2 订单毛利将变为 −19.10 元）
    
*   同设备 / 同 IP / 同收货地址批量注册不发券，已发券作废
    
*   薅券收益 6.35 元（1 张通用券 + 3 张免运费券）需 3 个真实注册账号，接码成本约 3–9 元，无利可图
    

## 价格锚点

上海美罗城 SHONEN JUMP SHOP 的官方印刷卡片约 10 元 / 张、一包 4 张约 40 元（现场按需打印单价未核实，待补）。**9.9 元 / 张是 SOD 的定价上限**，正好卡在这个市场锚点之下；4 张 35.6 元相较一包 40 元便宜约 11%，且为自定义图案。

## 凑单与防流失

阶梯按总张数计算，意味着用户可能「先做几个设计再一起下单」，创作周期拉长、存在冷静流失风险。应对：

1.  **包邮券兜底**：新用户 1 张即可下单，不必凑
    
2.  **用实付差额话术**：结算页提示「再加 1 张，只需多付 X 元」——两个钩子按强度排序：
    
    *   **最强：1 张 → 2 张，第二张只要 4.9 元**（14.9 → 19.8，因为第 2 张起免运费）
        
    *   **次强：4 张 → 5 张，第 5 张只要 5.9 元**（35.6 → 41.5）——这是主动引导的目标点，5 张是「多做几个设计一起下单」自然能到的量级，用户不必苦等凑单
        
3.  **加量优先走「加份数」**：同一作品加份数是 1 秒动作，不引导「再做一个设计」这类重动作
    
4.  **结算袋持久保存**：作品与结算袋不因离开而丢失
    
5.  不使用倒计时、弹窗等强提醒——目标人群反感
    

## 备选方案 B（未采用，留档备查）

全单重定价、只留 3 档的版本，优点是规则最短，缺点是底价不够低。

| 总张数 | 单价 | 用户实付 | 毛利 |
| --- | --- | --- | --- |
| 1 | 9.9（＋运费 5） | 14.9 | 4.55 |
| 2 | 9.9 | 19.8 | 5.90 |
| 3–4 | 8.9 | 26.7 / 35.6 | 9.25 / 14.60 |
| 5–9 | 7.9 | 39.5 / 47.4 / 55.3 / 63.2 / 71.1 | 14.95 / 19.30 / 23.65 / 28.00 / 32.35 |
| ≥10 | 7.9 | 79.0（10 张） | 36.70 |

毛利单调递增 ✓，但**已到全单重定价的极限**：N = 4 → 5 的边际毛利只有 +0.35 元（用户多付 3.9 元、成本增 3.55 元），再往下加档必然塌陷。

**未采用原因**：底价 7.9 元吸引力不足（此前评估 7.5 元档已被否决），且该结构无法容纳「第 5 张 5.9」这个钩子——按约束公式 `b < (P − 3.55)/(P − P')`，5.9 档在全单重定价下的起点最晚只能是第 2 张。

> **注意 B 在中段反而更便宜**：B 的 N = 5 为 39.5 元（我方毛利 14.95），低于现方案的 41.5 元（毛利 16.95）。B 是拿中段毛利换规则简洁，且底价 7.9 在大单上会输给现方案的 5.9（N = 10：79.0 vs 71.0）。

**何时可回头考虑**：若累进计价在用户测试中显得"算不明白"，而愿意接受 7.9 元底价。

# 用户旅程（核心创作流程）

> MVP 主流程。**AI 抠图调用云端服务**，原图需上传至服务器处理，隐私按文末底线执行。

## 主流程

| # | 阶段 | 用户动作 | 系统响应 | 备注 |
| --- | --- | --- | --- | --- |
| 0 | 进入并登录 | 打开 Web App，用微信或手机号登录 | 登录后进入创作 | 进入即要求登录——实现简单、数据干净（代价：创作前设卡） |
| 1 | 新建作品 | 点击「开始 DIY」 | 创建一张 7 寸相纸的空白画布 | MVP 只有一种纸张规格 |
| 2 | 上传图片 | 上传 JPEG / PNG（建议补 HEIC） | 图片进入素材区 | 支持一次上传多张 |
| 3 | AI 抠图 | 选中图片，点击「抠图」 | 上传至云端抠图服务，返回去背结果 | 云端处理 |
| 4 | 抠图修补 | 用橡皮 / 恢复笔刷修边缘 | 实时更新 | MVP 必备：抠图无法 100% 准确，无修补手段用户会卡死 |
| 5 | 排版 | 在画布上缩放、旋转、移动、调层级，摆放多个贴纸图案 | 实时渲染 | 一张相纸内可排若干个 |

| 7 | 预览与校验 | 查看最终效果（含模切轮廓 / 白边） | 越界、超出安全区时提示 | 边距与安全区规则待 S1 PRD |
| 8 | 保存 | 继续编辑或退出 | 自动保存为草稿 | 登录后可在「我的作品」查看 |
| 9 | 加入结算袋 | 完成一个作品后加入结算袋，可继续创作下一个 | 结算袋累计多个作品，每个可设份数 | 聚合的是用户自己的作品，非商品购物车 |

## 隐私底线（因抠图上云而重新定义）

AI 抠图走云端后，原图必须上传，「原图不出用户设备」不再成立。隐私仍属必备属性（做不好体验极糟），按以下底线执行并在产品内说明：

*   原图仅用于生成抠图结果，**处理完成即删除**，不留存、不挪作他用
    
*   传输全程加密
    
*   上传前以简明文案告知用户，避免「照片被陌生人拿去」的顾虑复发
