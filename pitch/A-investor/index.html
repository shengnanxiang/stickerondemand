第一章 · 本质

十年后，什么依然成立？

以极低的成本，把「我在乎的东西」变成「看得见、摸得着、能贴出去的实体」。

技术、载体、玩法、IP、渠道、人群标签都会变——它们是手段，不是本质。
本质 · 三个不变要素 → 硬约束
不变要素含义MVP 排除 / 约束
我在乎的内容来自「我」，非商家不依赖独家 IP / 不做官方授权 / 不做模板商城与社区
物化（可触摸）离开屏幕，进入物理世界纯线上形态非战场；实体交付是本体
低成本 + 随手可做便宜到可日常挥霍无硬件投入、无起订、单张低价、编辑器门槛极低
做
  • 任意内容 → 一张起印 → 送货上门的管道
  • 管道效率 + 数据复利
  • 用户上传自己的图，亲手设计
不做
  • 独家 IP / 官方内容授权
  • 模板商城 / UGC 市场 / 作品社区
  • AI 生图（MVP）
本质 · 稀缺位置的位移 + 两条长线
过去当下
想要的拥有喜欢的卡通形象拥有我指定的那个形象/照片
被什么挡住购买力（钱不够）供给缺口（官方只印它想印的）
稀缺的位置买不起买不到

诉求一分没动，挡住它的原因从「钱」移到了「供给」。

① 管道即资产：长线积累「任意内容→低成本实体贴纸」这条管道本身，不押某个玩法或 IP。
② 基础设施型，非内容型：护城河只有两条——管道效率（更便宜更快更简单）与数据复利（作品库/创作习惯/审美偏好）。
第二章 · 定位

一句话定义

SOD 是「在线创作—下单—送货上门」的贴纸 DIY 服务：用户上传自己的图，在浏览器里亲手设计，不用买机器、不用凑起订量，成品贴纸直接送到手上。

愿景让「把自己的东西变成贴纸」成为年轻人表达自我的日常方式——想做就做，做了就贴，贴了就晒。
定位 · 核心价值

需求已被验证

极印 S1 一体机以 AI 抠图 + 热升华打印 + 模切工艺，证明「撕下可贴、防水耐久」的个性化贴纸需求真实存在。

消除 1500 元门槛

S1 售价近 1500 元、耗材 36 张 99 元，对年轻群体硬件投入过高。SOD 把这道门槛拆掉——不买机器，也能得到机器做出来的贴纸。

亲手创作 = 当期差异

相比闲鱼/淘宝「传图代做」，SOD 的差异是在浏览器里亲手调整、实时预览，成品带「这是我做的」归属感。

不碰「正版」

不与官方授权制品竞争。卖的是「我自己做了什么」，不是「拥有官方制品」。定位与对外表述一律不碰「正版」二字。

「亲手创作」是当期差异化手段，非本质——一旦出现更省力方式（如一句话生成），被替代的首先是它。不变的那层始终是：以极低成本把「我在乎的东西」变成实体。

第三章 · 用户洞察

核心目标人群

年龄 / 阶段

15–25 岁学生（高中、大学）与初入职场新人；年轻父母，含养宠物的「毛孩子父母」。

城市 / 心智

一线最优、二线次之，初期不覆盖下沉。悦己 + 社交分享买单，情绪与表达价值优先，便宜到不心疼。

当期入口人群

手帐 / 潮玩 / 谷子（周边收藏）爱好者——「在乎」最强烈、供给缺口最明显、转化最快。

本质人群：有想物化的东西、且现有供给够不到的人。入口人群是其中转化最快的一批。

场景 · 手帐 / 谷子 / 潮玩（起步核心）

手帐与日记装饰

照片、贴图抠出来排版，做成装饰手帐本、日记的贴纸。

痛包与谷子展示

自制角色/偶像小卡、吧唧，用于痛包夹层、痛桌、痛收纳。

潮玩衍生

自制立牌、展示板贴纸，作为亚克力摆件的平价替代。

场景 · 学生 / 亲子 / 宠物 / 聚会

校园 / 情侣 / 旅行

社团班级物料、毕业纪念；合照互赠贴手机壳水杯；旅行照贴行李箱。

亲子成长

孩子成长、家庭日常做成贴纸，贴冰箱、成长册、儿童房。

聚会 / 物件点缀

庆生贴纸可延伸至婚礼、节日、伴手礼；贴单车、头盔、滑板彰显个性。

洞察 · 痛点 → 需求

痛点

  • 硬件门槛高：一体机近 1500 元 + 耗材，年轻群体没法随时为创意买单。
  • DIY 参与感弱：闲鱼/淘宝代做只传图等收货，缺亲手调整的乐趣。
  • 隐私顾虑：手帐、庆生、宠物贴纸常含个人照片，传给小作坊有外流风险。

需求

  • 零硬件在线创作：Web 端亲手做，免 1500 元机器与耗材。MVP 只做 Web App。
  • 能做出成品的编辑器：AI 抠图、素材与起点模板、实时预览，从上传到成稿看得见结果。
  • 单张低价、无起订：一张（7 寸相纸）即可下单，想排几个图案就排几个。

旅程 · 关键节点

AI 抠图上云

排版/预览在浏览器端完成；AI 抠图调用云端服务，原图需上传。隐私底线：处理完成即删除、全程加密、上传前告知。

一张起订

一张 = 一张 7 寸相纸，上面可自由排布若干贴纸图案。没有传统印刷动辄数百张的起订量。

结算袋（非购物车）

一次结算聚合多个不同作品，每个可设份数，按总张数计价。里面装的是用户自己的作品，不是待售商品。

履约

订单导出为可打印文件（一张相纸一个文件，复用 S1 拼版规则），发货回填物流。状态：待支付→制作中→已发货→已完成（超时关单）。

计价规则 · 为什么用累进

累进计价（采用）

第 N 张的价格只作用于这一张，不给前面已计价的张数退差价。每张边际价都高于 3.55 元变动成本，毛利天然单调递增，且保住「第 5 张起 5.9」这个钩子。

全单重定价（否决）

实测：买 4 张 31.6 元、买 5 张 29.5 元——多买一张反而便宜 2.1 元，毛利从 10.60 塌到 4.95。约束公式 b ≤ (P−P')·P⁻¹ 决定 5.9 档起点最晚只能是第 2 张，第 5 张绝无可能。

运费

N=1 收 5 元；N≥2 包邮。运费落差发生在金额最小、毛利最可控的第一档。

阶梯口径

按「一次结算的总张数」计，不绑定同一设计份数——可做几个不同设计一起下单。

底价提前

第 5 张（41.5 元）是「多做几个设计一起下单」自然能达到的量级，折扣才真正起作用。

回本测算 + 锚点 + 防流失

回本

第二单毛利（N=2 包邮）5.90 元，是 2.12 元 CAC 的 2.8 倍——单用户下第二单即回本。整体回本需 ≥36% 获客用户产生第二单。薅首单即走净亏 2.12，真实成本取决于留存。

价格锚点

上海美罗城 SHONEN JUMP SHOP 官方印刷卡片约 10 元/张、一包 4 张约 40 元。9.9 是 SOD 定价上限，卡在锚点之下；4 张 35.6 较一包 40 便宜约 11%，且为自定义图案。

凑单防流失

① 免邮券兜底，1 张可下单；② 话术钩子：1→2 张「第二张只要 4.9」、4→5 张「第 5 张只要 5.9」；③ 加量优先走加份数（1 秒动作）；④ 结算袋持久保存；⑤ 不用倒计时/弹窗。
