市场 — 竞争者漏出来的破绽

六条破绽，条条可打

① 慢（全场结构性）

所有平台「上传→中央工厂→快递 3-7 天」；NGA 用户提醒柔造「预留制作和发货时间」；小单排大单后面。归属：平台型全体

② 按批不按张

一件起订 ≠ 按张计价；无累进凑单结构。归属：平台型全体

③ 不能亲手调

工具全是「上传为主+模板辅助」；代做更是只传图等收货。归属：平台型 + 代做

④ 隐私顾虑

代做不敢传私人照片（手帐/庆生/亲子/宠物照片即隐私）。归属：代做小作坊

⑤ 1,500 元门槛

年轻群体买不起也不常用，闲置浪费。归属：自购硬件

⑥ 价格战已打穿

吧唧 ¥0.99、小卡 ¥0.5——拼单价的路已挤满 7+ 家。归属：平台型全体

市场 — 从竞争看机会

三个字，没人同时占住

尝试方向 · 非结论
快
全场 3-7 天，慢是结构性痛点——同城当日达是我们的尝试，尚未证明
亲手
浏览器里自己排版、实时预览，到手是「这是我做的」
按张

五平台共同指向一个空白：没有人做「即时创作 + 就近履约」；「高体验 × 低价」象限无人占据。我们带着不同入场券（S1 硬件资产）入场，不打价格战、不做「又一个柔造」。

用户 — 使用场景

内容是「我在乎的」，图是现成的

谷圈线 · 周级高频

给喜欢的角色做无料（漫展交换礼物）；痛包痛桌装饰；吧唧自制；手帐贴纸月度补充。

亲子线 · 事件驱动

孩子照片做成贴纸贴冰箱/成长册/儿童房；全家旅行照做纪念贴纸；生日礼物。

宠物线 · 情感浓度高

宠物抠图贴猫爬架/宠物用品/手机壳——毛孩子家长为孩子做贴纸的心智。

共性：内容是「我在乎的」（角色/孩子/毛孩子），图是现成的（有图人群），情感价值 > 功能价值。

用户 — 痛点与机会

需求被「半满足」，痛感明确

痛点四条（PCV 验证 10/12）

  • 价格 c：自购 1,500 元门槛 + 耗材 2.75 元/张；819 元机器要印大几千张才回本
  • 质量 c：代做质量参差、无模切（到手自己剪）、不敢传私人照片
  • 便利 c：家印要维护喷头学软件；代做流程繁琐（传图-沟通-确认-等待）
  • 效率 b：代做往返沟通慢（改一版等半天），发货 3-7 天

从用户看，机会在哪里

  • 亲子/宠物线是竞争真空——柔造映糖全在谷圈饭圈厮杀，无人服务
  • 亲子/宠物线是隐私痛点最锐利的场景——照片即隐私
  • 谷圈线是密度与复购的来源——周级高频 + 订阅制心智
  • 双线并行，用数据说话——分渠道 CAC/转化/客单/复购，Phase 0 定主次
第三章 · 定义

一句话定义

SOD 是「在线创作—下单—当日到手」的贴纸 DIY 服务：上传自己的图，在浏览器里亲手设计，不用买机器、不用凑起订量，按张计价，成品就近履约当日达/到店自提。

认知传播句「不用买机器，也能把喜欢的做成贴纸。」——用户不知道这个选项存在：我们创造认知，不是回应搜索。

口语化版本：「把你在乎的东西，变成能贴出去的实体。」

定义 — 卖点 = 竞争破绽 × 用户痛点

三个卖点打组合拳，一个方向在验证

亲手

浏览器里自己排版、实时预览，到手是「这是我做的」。
打：工具全是上传型 + 代做零参与感

隐私

创作在自己设备完成，抠图上云即删。
打：代做把照片交给陌生人 → 亲子/宠物照片不敢外传

按张

一张起订、累进计价（第 5 张起 5.9）。
打：全场按批卖 → 1,500 元门槛被拆掉

快 · 尝试中

同城当日达/到店自提。
打：全场 3-7 天 → 即时满足。尚未证明，见下页

不打
  • 价格战（吧唧 ¥0.99 已打穿）
  • 「又一个柔造」（聚合派单模式）
定义 — 关于「快」：我们的尝试清单

不下结论。列我们要尝试什么

1
同城自营节点：打印+模切设备在同城，截断「中央工厂+快递」链路 ——需实测单节点日产能上限与成本
2
自提点挂机：谷子店/文具店/校园店寄放设备，顺路取 ——需谈 2-3 家验证挂机话术（给店家带客流）
3
闪送补位：当日达订单同城闪送 ——需测单量阈值下的阶梯价是否撑得住客单
4
漫展/快闪现场履约：现场下单半小时自取 ——「快」的终极展示，也是地推获客
5
承诺分层：贴纸当日达 → 吧唧次日达 → 逐级放开 ——不提前透支承诺

验证标尺 = Gate 0 的当日达兑现率 ≥80%。做不到，就把「快」降级为次日达叙事，回供给布局层重审。先做到，再说话。

第四章 · 终局

终局一句话

消费端创作平台 + 分布式微产能履约网络：SOD 品牌直连消费者做入口，购买商家套件的小商家与个人用户就近履约。

收入三线叠加

订单毛利 + 硬件 + 耗材 + 佣金——比纯佣金平台更厚

滴滴 = 结构类比

平台接单、节点履约——后置实施，Phase 0 只做自营

Sticker Mule = 收入镜子

产品毛利驱动，非纯佣金

UE — 敏感变量（Phase 0 重点实测）

四个杠杆，自提最大

自提占比

自提省 5 元运费/单，是单均 UE 最大杠杆——这就是自提占比 ≥40% 进 Gate 0 的原因。

履约人力效率

人工 0.8 元/张是半人工估算，流程熟练+并单打印后降幅最大——跑单账本记「人力分钟数」正是为此。

复购

第二单毛利 5.90 元 > CAC 期望 1.60 元，回本只需 ≥36% 用户下第二单——复购 ≥15% 是底线，36% 是回本线。

获客成本

CAC 期望 ~1.60 元/人（SOD.md 测算锚），双入口实测可能上浮——分渠道记录，不买量。

纪律框架先行，具体数字待 Phase 0 实测校准；人工项按半人工估算，是最不确定、规模化后降幅最大的一项。
第七章 · 为什么不 — 质疑预答复（上）

三个「为什么不做」

Q1
「跟代打价格战吧，5 元 200 张都有了」→ 不打。
价格锚已被若映（吧唧 ¥0.99）打穿，拼单价毫无胜算；打「亲手+隐私+模切+快」组合拳，免费打样抵消首次尝试摩擦。
Q2
「为什么不先做小程序？竞品都是小程序」→ Web 先行。
探索期定义未稳，Web 迭代最快（GitHub 部署浏览器即看）；竞品全选小程序恰说明要 A/B 验证入口损耗；编辑器核心与 UI 解耦保证后切 App 可复用。
Q3
「买套现成电商后台不就完了」→ 不买。
市面不存在「按需贴纸生产调度」垂直方案（电商 SaaS 是店铺逻辑、外卖 SaaS 是餐饮逻辑）；拼版与派单是差异化本体，能买到的都不是壁垒；Phase 0 用飞书表格跑单学需求。
为什么不 — 质疑预答复（下）

再三个「为什么不做」

Q4
「加上 AI 生图更有卖点」→ MVP 不做。
每次调用是实打实的接口成本，且分散编辑器打磨注意力；核心双 ICP 均为「有图」人群（柄图/孩子照片/宠物照片都是现成的），AI 生图是 Phase 1+ 期权。
Q5
「学滴滴补贴抢用户」→ 不补贴。
补贴买不来复购只买来羊毛党；单均经济必须自己站得住（Gate 0 UE 边际 ≥0），免费打样/免运费券已够降低首次尝试门槛。
Q6
「直接上商场常驻 kiosk 投放」→ Phase 0 不上。
月租数千-数万+进场费+人员维护，万元级有界投入约束下不是起点；先用漫展摊位（数千元/场）和商场快闪位（数百-数千元/日）做对照实验，数据说话后再决定 Phase 1 押不押。
总结

先做到，再说话

全场都慢、都不能亲手调、都按批卖——我们用「快（待验证）、亲手、按张」占住这个真空；亲子/宠物线与谷圈线双入口并行，Phase 0 十二周拿数据定主次；UE 框架已立、数字待实测；每一步都有 Gate 门槛纪律。
